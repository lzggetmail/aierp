# OpenClaw Workspace - AI 指令文件

> 基于 OrbitOS 结构，适配 OpenClaw 使用场景

## 核心理念

以用户（李志刚）为中心，所有知识围绕你运转。

### 核心原则
1. **以用户为中心** - 所有内容都与志刚的需求和目标相关
2. **双向链接** - 通过 `[[]]` 建立知识之间的联系
3. **渐进整理** - 从快速捕获开始，逐步组织成结构化知识

---

## 目录结构

| 目录 | 用途 | 对应 OrbitOS |
|------|------|-------------|
| `00_收件箱/` | 快速捕捉，未整理的内容 | 00_收件箱 |
| `10_日记/` | 每日记录、学习笔记 | 10_日记 |
| `20_项目/` | 正在进行的项目 | 20_项目 |
| `30_研究/` | 主题研究、深度分析 | 30_研究 |
| `40_知识库/` | 永久笔记、概念卡片 | 40_知识库 |
| `50_资源/` | 技能、工具、参考资料 | 50_资源 |
| `90_计划/` | 规划、目标 | 90_计划 |
| `99_系统/` | 配置、模板、核心文件 | 99_系统 |

---

## 核心文件

| 文件 | 用途 |
|------|------|
| `MEMORY.md` | 长期记忆索引 |
| `USER.md` | 用户画像（背景、偏好） |
| `SOUL.md` | AI 人格定义 |
| `AGENTS.md` | 工作区规则 |
| `HEARTBEAT.md` | 心跳任务配置 |

---

## 工作流程

```
新想法/任务
    ↓
00_收件箱/（快速捕获）
    ↓
整理后迁移到：
    - 20_项目/（如果是项目）
    - 30_研究/（如果是研究主题）
    - 40_知识库/（如果是概念）
    ↓
10_日记/（每日记录进展）
    ↓
MEMORY.md（长期记忆索引）
```

---

## 使用规范

### 每日记录
- 文件命名：`YYYY-MM-DD.md`
- 存放位置：`10_日记/`
- 用 `[[]]` 链接到相关项目和知识点

### 项目管理
- 存放位置：`20_项目/`
- 每个项目一个文件夹
- 包含 README.md 说明项目目标

### 知识沉淀
- 存放位置：`40_知识库/`
- 按类型分：框架/人物/工具
- 使用双向链接

---

## AI 读取优先级

1. `MEMORY.md` - 长期记忆（最重要）
2. `USER.md` - 了解用户
3. `10_日记/YYYY-MM-DD.md` - 今日/昨日记录
4. 当前对话上下文
