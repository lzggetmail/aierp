## 一、工程部分分类

### 1. 硬装工程（可自施工或分包）

| 项目 | 客户报价 | 核算要点 |
|------|----------|----------|
| 轻钢龙骨隔墙 | 128.75万 | 龙骨+基层板+面层铝板，按m²算量 |
| 吊顶天棚 | 38.17万 | 龙骨+蜂窝铝板+灯槽 |
| 自流平地面 | 9.54万 | 找平层+自流平材料 |
| 金属踢脚线 | 4.80万 | 不锈钢/铝合金 |
| 钢化玻璃门 | 1.23万 | 12mm钢化玻璃+五金 |

**成本核算公式：**
```
硬装成本 = 材料费 + 人工费 + 机械费 + 管理费

材料费 = 工程量 × 材料单价
人工费 = 工程量 × 人工单价（或工日数 × 日工资）
机械费 = 台班数 × 台班单价
管理费 = (材料费 + 人工费 + 机械费) × 5-8%
```

## 二、工程成本核算步骤

### Step 1：算量（工程量计算）

根据设计图纸计算：
- 隔墙面积（m²）
- 吊顶面积（m²）
- 地面面积（m²）
- 踢脚线长度（m）
- 电缆长度（m）
- 设备点位数（个）

### Step 2：询价（材料+人工）

**材料价格来源：**
- 供应商报价（你们有采购渠道）
- 市场询价
- 信息价（当地造价信息）

**人工价格参考：**
- 木工：300-500元/工日
- 电工：350-500元/工日
- 油漆工：300-450元/工日
- 普工：200-300元/工日

### Step 3：分包询价

**建议分包项目：**
1. 机电安装 → 找专业机电公司
2. 弱电系统 → 找弱电集成商
3. 多媒体制作 → 找数字展示公司
4. 模型制作 → 找专业模型公司

**分包询价清单：**
- [ ] 机电安装分包报价
- [ ] 弱电系统分包报价
- [ ] 多媒体制作分包报价
- [ ] 安防系统分包报价

### Step 4：汇总成本

```
总成本 = 自施工成本 + 分包成本 + 设备采购成本

自施工成本 = 材料费 + 人工费 + 机械费 + 管理费
分包成本 = 各分包商报价之和
设备采购成本 = 设备清单 × 采购单价
```

## 三、成本控制建议

### 1. 自施工 vs 分包选择

| 项目 | 建议 | 原因 |
|------|------|------|
| 隔墙/吊顶/地面 | 自施工 | 常规工艺，利润可控 |
| 机电/弱电 | 分包 | 需要资质和专业人员 |
| 展陈制作 | 部分自做 | 高利润，但需要工艺能力 |
| 多媒体内容 | 分包 | 专业性强 |
| 设备采购 | 自采购 | 有采购渠道优势 |

### 2. 利润空间分析

| 类别 | 客户报价占比 | 建议成本率 | 毛利率 |
|------|-------------|-----------|--------|
| 硬装 | 15% | 70-75% | 25-30% |
| 软装 | 26% | 60-65% | 35-40% |
| 机电 | 8% | 75-80% | 20-25% |
| 展区内容 | 35% | 55-65% | 35-45% |
| 其他 | 16% | 70-80% | 20-30% |

### 3. 风险控制

**预留风险金：总成本的5-8%**

常见风险：
- 设计变更（展厅项目变更频繁）
- 材料价格波动
- 工期延误
- 返工整改

## 四、快速核算工具

已在成本核算模板中设置以下列：

| 列 | 用途 |
|----|------|
| I - 材料成本 | 填入材料费 |
| J - 人工成本 | 填入人工费 |
| K - 设备成本 | 填入设备采购费 |
| L - 外包成本 | 填入分包报价 |

**公式自动计算：**
- 成本合计 = I + J + K + L
- 毛利 = 你的报价 - 成本合计
- 毛利率 = 毛利 / 你的报价 × 100%
