## Claude Code vs OpenClaw 实践 (2026-03-10)

### 尝试背景

视频教程提到：不装OpenClaw，也可以用飞书对接Claude Code实现类似功能。

### 志刚的判断

| 对比 | OpenClaw | Claude Code |
|------|----------|-------------|
| 位置 | 云端服务器 | 本地电脑 |
| 安全感 | 需要云端权限，有顾虑 | 本地控制，安全感更强 |
| 飞书对接 | 原生支持 | 需要额外配置，有网络限制 |
| 硬件要求 | 云服务器 | 本地电脑 |

### 实践结果

**尝试**: 飞书 + Claude Code（本地）替代 OpenClaw

**过程**:
1. ✅ 配置飞书对接
2. ✅ 安装Claude Code
3. ✅ 安装MCP接口
4. ✅ 通讯可以打通
5. ❌ 失败：网络通讯限制，Claude Code提示需要云端版Claude API

**结论**: 放弃。云服务器运行环境不足以支撑Claude Code。

### 关键认知

- 志刚更信任本地运行的AI（安全机制、控制权）
- 飞书对接本地AI有技术门槛和网络限制
- 这是很多人的痛点：想用本地AI但配置复杂

1. 跨会话 — 内容在另一个会话里，AI看不到
2. 没存进文件 — 内容只在对话中，没有写入MEMORY.md或daily文件
3. 不同渠道 — 可能是另一个飞书会话

### AI的记忆机制

| 机制 | 说明 |
|------|------|
| 对话上下文 | 当前对话窗口里的内容（关掉就没了） |
| MEMORY.md | 长期记忆文件（每次会话会读取） |
| memory/*.md | 按日期的记录文件 |
| 项目文件 | 各个项目文件夹里的内容 |

**AI没有连续意识，每次新会话是"白纸"。靠文件系统维持记忆。**

### 协作改进

**对AI的要求**:
- 重要对话后，主动存入文件
- 信息缺失时，坦诚告知用户

**对志刚的建议**:
- 重要信息，明确说"记录下来"
- 如果AI忘了，再发一次——这是"喂养"记忆的过程
- 理解为"培养合伙人"，不是"使用工具"

### 核心洞察

> AI的记忆 = 文件系统，不是人脑
> "喂养"AI的记忆 = 帮它建立你的上下文
> 这是合伙人的必修课：理解彼此的边界

#### 管理风格

**核心打法：攻心术（五层心理操控）**

| 层次 | 手法 | 效果 |
|------|------|------|
| **1. 身份绑定** | "既然担了这个头衔，就应该干团长的事儿" | 让人觉得有责任 |
| **2. 归属感制造** | 改微信名、统一格式 | 让人觉得"我是团队一员" |
| **3. 愧疚感植入** | "99.9%是被挂名的" | 让人觉得亏欠 |
| **4. 紧迫感灌输** | "未来20年必须打赢" | 让人觉得不干不行 |
| **5. 二选一施压** | "不想当的，开门左转" | 不服就走，制造服从 |

#### 销售话术特点

**1. 问题处理策略**
- "不要跟客户纠结问题"
- "把问题抛回来，说下次升级解决"
- "不要浪费时间在纠结的人身上"

**2. 话术框架**
- "我们只做了一个动作，搭了一个大模型"
- "整个全域你都可以进来"
- "你只要是个人，你都跑不了"

**3. 信心传递**
- "一定要给客户信心"
- "千万不要说负面的话"
- "你一旦说负面，那就全是问题了"

**4. 转化逻辑**
- "付费客户比推荐官值钱多了"
- "他一进来交费就有钱了"
- "这是最核心的转换"

#### 动员流程（四步）

```
第一步：立威
   ↓ "不想当团长的，开门左转"

第二步：统一符号
   ↓ 改微信名，建立归属感

第三步：制造紧迫
   ↓ "未来20年必须打赢"

第四步：给出最简动作
   ↓ 不教方法，只给"信念"

结果：一群人改了名字，热血沸腾，但不知道具体怎么干
```

#### 志刚的评价

**这套打法的本质：**

| 表面 | 实质 |
|------|------|
| 激励士气 | 立威、服从测试 |
| 讲"状态"和"信念" | 因为没有实质方法可教 |
| 让人改微信名 | 最简单的"服从性测试" |
| 强调"使命" | 用宏大叙事掩盖产品问题 |

**核心逻辑：**
```
产品不行 → 卖不动 → 请"商学院院长" → 讲状态、讲信念 → 团长改微信名 → 还是不行 → 换人继续讲
```

**这是典型的"用管理弥补产品缺陷"的路径。**

#### 志刚可以学的

**话术技巧（可用）：**
1. 不跟客户纠结细节问题
2. 把问题转化为"未来升级"的承诺
3. 强调信心，不说负面
4. 仪式感 + 归属感的营造技巧

**要警惕的（模式陷阱）：**
1. 这种打法短期有效，长期不可持续
2. 产品不行，动员再多次也没用
3. 这套玩法是"销售洗脑"，不是"价值传递"
4. 志刚作为团长，只是分销小角色，不需要太投入
