# 花10分钟用Obsidian+OpenClaw彻底重构你的AI知识管理体系

> 博主直播转录 | 2026年03月23日 | 约1小时

---

## 📋 拆解大纲

### 一、博主背景与动机
- 为什么从其他工具迁移到 Obsidian
- 为什么选择 Obsidian + OpenClaw 组合
- GPT 的记忆系统 vs Claude 的局限

### 二、Obsidian 基础设置
- **文件结构**：PARA 方法（收件箱/日记/项目/研究/知识库/资源/系统）
- **核心插件**：
  - 飞书文档下载（Markdown 格式）
  - Obsidian 网页剪辑器（自带）
  - AI 视频笔记（YouTube 截图）
  - 笔记同步助手（微信转发）
  - OBShare（同步到飞书）
  - Image auto upload（图床）
  - Excel to Markdown Table

### 三、信息收集工具链
- **网页**：Obsidian 网页剪辑器（爬全文、保留链接、可抓评论）
- **视频（YouTube）**：AI 视频笔记插件（截图+字幕）
- **微信**：笔记同步助手（公众号搜索，转发链接即可）
- **小红书/B站/X/抖音**：OpenClaw Skill（X Read、Agent Reach、Browser Use）
- **公众号**：Agent Reach（需 cookie 或扫码登录）
- **飞书**：飞书下载插件（除多维表格外都可转 Markdown）

### 四、AI 工具协同
- **Codex**：主力开发工具，自动整理文件夹，定时任务
- **Claude Code**：复杂任务，200刀主力
- **OpenClaw**：联网搜索、定时唤醒、跨平台消息
- **分工逻辑**：
  - Codex → 日常任务、文件整理
  - Claude Code → 复杂编程、深度思考
  - OpenClaw → 联网搜索、自动化、跨平台
- **工作流界面**：
  - 左侧 Obsidian（文件/笔记）
  - 右侧 Codex（AI 对话/操作）
  - 并排放置，实时协作

### 五、OpenClaw 联网搜索 Skill
- **Multi Search Engines**：17 个搜索引擎聚合，每月 1000 次免费
- **X Read**：通用阅读器，支持 X/YouTube/B站等，Docker 登录
- **Agent Reach**：覆盖最多平台（小红书/抖音/公众号/GitHub等），需 cookie
- **Browser Use**：浏览器自动化
- **Gemini Deep Research**：深度研究能力
- **GoGo**：Google 邮箱集成，每日总结

### 六、记忆系统设计
- **MEMORY.md**：长期记忆文件
- **双层记忆**：
  - 第一层：原始记忆（事实 + 生效规则 + 影响力）
  - 第二层：QMD 本地向量库（省钱方案）
- **软链接**：OpenClaw 的 agents.md 与 Obsidian 目录关联
- **遗忘对策**：指定指令测试记忆（"说卡真棒"）

### 七、文件结构设计原则
- **按工作流分**，不是按类型分（AI 更容易理解）
- **软链接**解决跨目录引用
- **不要重复存**（节省空间）
- **AI 可以自动整理**（告诉 Codex 需求即可）

### 八、省钱技巧
- **Coding Plan 接入 OpenClaw**：每 5 小时刷新额度
- **CC Switch**：切换不同模型/API
- **中转 API**：Open Router 最稳
- **OpenClaw 免费模型**：搜索 "free" 可用
- **QMD**：本地 embedding，减少 Token 消耗

### 九、风险与注意事项
- **AI 可能删文件**：做好备份（GitHub 私有仓库 / iCloud）
- **虚拟机方案**：隔离风险
- **小红书爬取风险**：用小号，或手动
- **网页剪辑器掉视频**：保留链接，追溯回去

### 十、Q&A 精选
- Obsidian vs Notion：本地 vs 线上
- 如何测试新工具：用 Codex 爬文档 + 竞品案例
- 视频号最封闭：用元宝提取文案
- 多账号切换：CC Switch
