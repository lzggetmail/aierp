## 🎯 核心概念：三件套笔记法

为什么要创建三个文件？

```
【原始】                          【整理】                        【思考）
完整转录原文        →→→         结构化提炼      →→→         个人理解和应用
（永久备份）                    （便于复习）                  （实际应用）
```

### 优势说明

| 文件类型 | 作用 | 什么时候看 |
|---------|------|-----------|
| 【原始】 | 完整备份，链接失效也不怕 | 需要查看完整表述时 |
| 【整理】 | 快速复习，结构清晰 | 日常学习回顾 |
| 【思考】 | 个人理解，应用场景 | 实际工作中参考 |

## 🚀 完整工作流程

### 阶段1：首次学习新视频

```
第1步：看视频 + 录音转录
   ↓
第2步：打开 "Obsidian笔记模板-三件套.md"
   ↓
第3步：复制模板内容 + 粘贴到AI对话框
   ↓
第4步：在模板末尾添加：
   - 视频标题
   - 博主名称
   - 视频链接
   - 转录原文（或原文关键部分）
   ↓
第5步：AI生成三个文件的内容
   ↓
第6步：在Obsidian中创建三个文件，粘贴内容
   ↓
第7步：检查链接是否正确（Ctrl+点击测试）
```

### 阶段2：后续复习

```
快速回顾：看【整理】文件
   ↓
需要细节：跳转【原始】文件
   ↓
实际应用：参考【思考】文件
```

## 🔧 Obsidian核心功能使用

### 1. 双向链接（最重要！）

**创建链接**：
- 输入 `[[` 会自动提示已有笔记
- 输入 `[[【整理】` 会提示所有整理笔记

**使用链接**：
- 按住 Ctrl 点击链接可跳转
- 点击后可快速返回（Ctrl+Alt+←）

**反向链接**：
- 在笔记右侧可以看到"反向链接"面板
- 显示哪些笔记引用了当前笔记
- 方便追踪知识关联

### 2. 标签系统

**标签层级设计**：
```
#AI学习                          # 一级：所有AI学习笔记
#AI学习/原文                     # 二级：原文转录
#AI学习/OpenClaw                # 二级：细分领域
#AI学习/Agent应用               # 二级：应用方向
#评分/⭐⭐⭐⭐⭐                 # 评级标签
```

**搜索标签**：
- 点击任意标签可查看所有相关笔记
- 左侧搜索框输入 `#标签名` 可筛选
- 组合搜索：`#AI学习 #OpenClaw`

### 3. 快速定位

在【整理】笔记中标注了时间戳后：
- 直接在视频平台拖拽进度条到对应时间
- 或在【原始】文件中搜索关键字定位

## 💡 实用技巧

### 技巧1：在原文中快速标注

看原文时，快速添加标签标记重点：

```
#重点        - 核心知识点
#实操        - 可操作的方法
#工具/XXX    - 提到的工具
#观点/XXX    - 重要观点
#疑问        - 不理解的地方
#待整理      - 需要提炼到整理笔记
```

### 技巧2：时间戳记录

看视频时，看到重点内容记下时间：

```
## 00:05:30 Agent的核心定义

博主详细解释了Agent的三个要素...

#重点 #待整理
```

### 技巧3：推荐指数标记

在看【原始】文件时，快速评估价值：

```
- **推荐指数**：⭐⭐⭐⭐⭐（1-5星）
```

这样后续复习时可以优先看高星内容。

## 💾 备份与版本管理

### 为什么要备份到GitHub？

- ✅ 防止本地数据丢失
- ✅ 多设备同步（手机、电脑）
- ✅ 版本历史（可回溯）
- ✅ 方便分享（给朋友看你的笔记）

### 推荐的备份策略

```
公开仓库（GitHub）：【整理】、【思考】文件
                    ↓
            只分享有价值的提炼内容
                    ↓
本地保留：              【原始】文件（可选是否提交）
                    ↓
            完整的原文备份，本地访问
```

### .gitignore 配置（可选）

如果不想提交【原始】文件，可在仓库根目录创建 `.gitignore`：

```bash
# 忽略所有原始转录文件
Ai知识库/**/【原始】*.md

# 或者忽略某个分类的原始文件
Ai知识库/私人学习笔记/**/【原始】*.md
```

## 🆘 常见问题

### Q1: 【原始】文件太长，会不会影响性能？
**A**: Obsidian 处理大文件没问题，但如果超过 5 万字，建议分段保存。

### Q2: 每个视频都要创建三个文件吗？
**A**: 推荐这样做，保证知识完整性。如果是简单视频，可以只创建【整理】。

### Q3: 时间戳怎么快速获取？
**A**: 看视频时，看到重点内容直接记下时间（或截图），整理时补充。

### Q4: 有些链接失效了怎么办？
**A**: 这就是为什么要保存【原始】文件！原文中有博主的完整表述，不依赖链接。

### Q5: 如何找到之前的某个笔记？
**A**: 三种方法：
   1. 用标签搜索：`#标签名`
   2. 用全局搜索：Ctrl+Shift+F
   3. 看"反向链接"面板

### Q6: AI生成的笔记太长了怎么办？
**A**:
   - 可以在提示词中强调"精简"、"不要冗余"
   - 或只让AI生成【整理】文件，【原始】文件自己粘贴

### Q7: 怎么快速判断一个视频是否值得整理？
**A**:
   - 看完后快速评估：⭐⭐⭐以下不整理
   - ⭐⭐⭐只做【整理】，⭐⭐⭐⭐⭐做三件套
