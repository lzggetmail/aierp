# 项目示例：代码审查Agent

> **项目类型**：学习项目
> **开发时间**：2天
> **最终状态**：✅ 已完成并投入使用
> **战斗力转化**：✅ 已形成SOP和可复用经验

## 🎯 项目背景

### 初始需求
我发现自己写代码后经常忘记一些基本的审查要点：
- 代码风格是否一致
- 是否有明显的bug
- 是否有安全问题
- 是否有性能问题

每次都要手动检查，很费时间。想开发一个Agent帮我自动审查代码。

### 项目目标
- [x] 开发一个能自动审查Python代码的Agent
- [x] 覆盖常见的代码问题
- [x] 提供改进建议
- [x] 形成可复用的开发经验

### 最终成果
✅ **一个可工作的代码审查Agent**
✅ **一套完整的开发文档**
✅ **一份标准化的SOP**
✅ **多个可复用的经验笔记**
