# 项目示例：如何形成战斗力

> **核心问题**：从项目到"战斗力"的转化过程是怎样的？
> **示例项目**：代码审查Agent
> **转化周期**：2天
> **知识产出**：15篇文档 + 1个SOP + 多个可复用模式

---

## 🎯 什么是"战斗力"？

**战斗力** = 可复用、可执行、可改进的知识体系

### 战斗力的三个层次

#### 第1层：可运行的代码
```
写了一个Agent → 可以用
```
**价值**：⭐⭐
- 只能解决当前问题
- 难以复用
- 容易遗忘

#### 第2层：文档化的经验
```
写了一个Agent → 记录了开发过程 → 可以参考
```
**价值**：⭐⭐⭐⭐
- 可以回顾和学习
- 可以分享给他人
- 但难以直接复用

#### 第3层：系统化的知识
```
写了一个Agent → 提炼了SOP → 形成了模式 → 可以快速复现
```
**价值**：⭐⭐⭐⭐⭐
- 可以快速复现
- 可以持续改进
- 形成复利效应

**我们的目标**：达到第3层
