# 学习笔记：配对机制

**日期**: 2026-03-13
**主题**: 理解两种不同的配对

---

## 两种配对

| 类型 | 说明 | 命令 |
|------|------|------|
| **渠道配对** | 飞书/WhatsApp 和 OpenClaw 连接 | `openclaw channels login` |
| **设备配对** | 手机/电脑 和 OpenClaw 连接 | `openclaw nodes pair` |

---

## 渠道配对（飞书）

```bash
# 查看状态
openclaw channels status --probe

# 登录
openclaw channels login --channel feishu

# 登出（清除认证）
openclaw channels logout --channel feishu
```

---

## 设备配对（nodes）

```bash
# 查看已配对设备
openclaw nodes status

# 配对新设备
openclaw nodes pair

# 取消配对
openclaw nodes unpair --node <设备ID>
```

## 志刚的经历

之前做飞书配对时遇到问题，后来重新配对成功。

**教训**：配对出问题时，先登出再重新登录。

## ⚠️ 重要踩坑记录

### 配对命令只输入一次！

**问题**：输入两次配对命令导致失败

**错误做法**：
```bash
openclaw pairing approve feishu JPD6D53R
# 看起来"卡住"了，又输入一次...
openclaw pairing approve feishu JPD6D53R  # ❌ 报错！
```

**正确做法**：
```bash
# 只输入一次，耐心等待
openclaw pairing approve feishu JPD6D53R
```

**原因**：配对码是一次性的，输入两次会破坏配对流程

**如果卡住了怎么办**：
```bash
# 1. 清除认证
openclaw channels logout --channel feishu

# 2. 重新配对
openclaw channels login --channel feishu
```

**教训**：配对命令只输入一次，耐心等待！不要因为看起来"卡住"就重复输入。
