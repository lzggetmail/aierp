# 学习笔记：MEMORY.md 的安全风险

**日期**: 2026-03-13
**主题**: 另一个用户能否读取你的 MEMORY.md？

---

## 安全风险

**是的，理论上可以！**

如果另一个人问：
- "读取 MEMORY.md"
- "志刚是谁？"
- "这个系统记录了什么？"

**他可能会看到你的私人信息！**

---

## MEMORY.md 包含的信息

- 姓名、年龄
- 职业现状
- 核心思想
- 项目信息
- 人物档案
- ...

---

## 解决方案

### 方案1：多 Agent（推荐）

```json
{
  "bindings": [
    { "agentId": "zhigang", "match": { "channel": "feishu", "peer": { "kind": "direct", "id": "ou_eb2c662a..." } } },
    { "agentId": "other", "match": { "channel": "feishu", "peer": { "kind": "direct", "id": "ou_42468e..." } } }
  ]
}
```

**效果**：完全隔离，各自的 MEMORY.md

---

### 方案2：限制工具权限

```json
{
  "tools": {
    "deny": ["read", "edit"]
  }
}
```

**效果**：不能读取文件

---

### 方案3：只允许自己使用

在飞书开放平台配置用户白名单。

---

## 建议

**如果在意隐私，用方案1（多 Agent）！**
