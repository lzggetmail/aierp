# 学习笔记：多人共用时的记忆隔离

**日期**: 2026-03-13
**主题**: 你的记忆会不会影响另一个用户？

---

## 分析

### 他能看到什么？

| 内容 | 能看到吗 | 原因 |
|------|----------|------|
| 你的会话 | ❌ 不能 | 会话文件隔离 |
| 你的 MEMORY.md | ⚠️ 技术上可以 | 同一个 workspace |
| 实际影响 | ❌ 不会 | AI 不会主动提起 |

---

## 为什么不会影响？

1. MEMORY.md 是"背景知识"，不是"对话内容"
2. AI 不会主动说"志刚告诉过我..."
3. 他问天气，AI 只回答天气

---

## 例子

**MEMORY.md 里有**：志刚叫李志刚...

**他问**："今天天气？"

**AI 回复**："今天晴朗，25度..."

**AI 不会说**："志刚觉得今天天气不错..."

---

## 如果完全隔离？

用多 Agent + 绑定规则：

```json
{
  "bindings": [
    { "agentId": "zhigang", "match": { "channel": "feishu", "peer": { "kind": "direct", "id": "ou_eb2c662a..." } } },
    { "agentId": "other", "match": { "channel": "feishu", "peer": { "kind": "direct", "id": "ou_42468e..." } } }
  ]
}
```

**效果**：完全物理隔离，各自的 workspace 和 MEMORY.md
