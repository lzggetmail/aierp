# 学习笔记：多个机器人 vs 多 Agent

**日期**: 2026-03-13
**主题**: 理解多个机器人和多 Agent 的区别

---

## 对比

| 对比 | 多个机器人 | 多 Agent |
|------|-----------|----------|
| 定义 | 多个飞书应用（多个 App ID） | 一个飞书应用，多个龙虾 |
| 配置 | 飞书开放平台创建多个应用 | OpenClaw 配置文件添加 |
| 连接 | 多个长连接 | 一个长连接 |
| 冲突风险 | ⚠️ 高 | ✅ 无 |

---

## 架构对比

### 多个机器人（不推荐）
```
飞书应用1 → OpenClaw → 龙虾1
飞书应用2 → OpenClaw → 龙虾2
         ↑
      冲突！
```

### 多 Agent（推荐）
```
飞书应用 → OpenClaw
              │
              ├── main 龙虾
              ├── work 龙虾
              └── family 龙虾
```

---

## 志刚遇到的问题

**"配置另一个机器人时 APP ID 冲突导致死机"**

**原因**：用了多个机器人（多个 App ID）
**解决**：用多 Agent（一个 App ID，多个龙虾）

---

## 正确做法

只用一个飞书应用，通过 **多 Agent + 绑定规则** 实现。
