# 学习笔记：纠正"多龙虾"的理解

**日期**: 2026-03-13
**主题**: 纠正之前关于多龙虾的错误说法

---

## 之前的错误说法

❌ "养多只龙虾需要装多台服务器"
❌ "一台服务器只能装一个 OpenClaw 实例"

---

## 正确的说法

✅ **一台服务器可以养多只龙虾（多 Agent）**
✅ **多 Agent = 一个 OpenClaw + 多个独立龙虾**

---

## 正确的架构

```
一台服务器
    │
    └── 一个 OpenClaw
            │
            ├── main 龙虾（独立工作区、记忆）
            ├── work 龙虾（独立工作区、记忆）
            └── family 龙虾（独立工作区、记忆）
```

---

## 什么时候需要多台服务器？

- 不同地点部署
- 高可用（备份）
- 完全物理隔离（安全要求）

**多人共用不需要多台服务器！用多 Agent 就行！**

---

## 总结

| 之前说的 | 正确说法 |
|----------|----------|
| 多龙虾 = 多台服务器 | ❌ 错误 |
| 多龙虾 = 多 Agent = 一台服务器 | ✅ 正确 |
