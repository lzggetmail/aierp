# 学习笔记：多人共用时的绑定规则

**日期**: 2026-03-13
**主题**: 两个人用一个机器人，需要几个绑定？

---

## 情况

- 一个飞书机器人
- 两个人有权限使用

---

## 两种选择

### 选项1：共享龙虾（默认）

```json
{
  "bindings": [
    { "agentId": "main", "match": { "channel": "feishu" } }
  ]
}
```

**效果**：
- 两个人用同一只龙虾
- 共享记忆

---

### 选项2：隔离龙虾

```json
{
  "bindings": [
    {
      "agentId": "zhigang",
      "match": {
        "channel": "feishu",
        "peer": { "kind": "direct", "id": "ou_eb2c662a..." }
      }
    },
    {
      "agentId": "other",
      "match": {
        "channel": "feishu",
        "peer": { "kind": "direct", "id": "ou_xxxxxxx..." }
      }
    }
  ]
}
```

**效果**：
- 每个人用不同的龙虾
- 记忆隔离

---

## 总结

| 情况 | 绑定数量 | 效果 |
|------|----------|------|
| 共享龙虾 | 1个 | 记忆共享 |
| 隔离龙虾 | 2个 | 记忆隔离 |
