# 学习笔记：子代理（Sub-agents）

**日期**: 2026-03-13
**主题**: 派小龙虾去干复杂任务

---

## 什么是子代理？

**子代理 = 临时派出去的小龙虾**

主代理派一只小龙虾去处理任务，完成后汇报结果。

---

## 子代理 vs 多 Agent

| 对比 | 多 Agent | 子代理 |
|------|----------|--------|
| 存在时间 | 长期 | 临时 |
| 创建方式 | 配置文件 | 动态派发 |
| 适用场景 | 固定员工 | 临时任务 |

---

## 工作流程

```
复杂任务 → 派子代理 → 完成 → 汇报 → 返回结果
```

---

## 适用场景

- 复杂搜索
- 并行任务
- 长时间任务
- 隔离任务

---

## 你可以这样说

> "派一个子代理帮我搜索 xxx"
> "并行处理这几个任务"

---

## 优势

| 优势 | 说明 |
|------|------|
| 并行 | 同时派多个 |
| 隔离 | 独立环境 |
| 专注 | 只做一件事 |
| 汇报 | 自动返回结果 |

---

## 限制

- 任务完成后消失
- 消耗资源
- 消耗 API 调用
