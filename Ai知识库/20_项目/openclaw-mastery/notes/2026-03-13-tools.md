# 学习笔记：工具（Tools）

**日期**: 2026-03-13
**主题**: 理解龙虾的内置能力

---

## 什么是工具（Tools）？

**工具 = 龙虾的内置能力**

技能是外部安装的，工具是 OpenClaw 自带的基础能力。

---

## 常用工具

### 文件操作
| 工具 | 功能 |
|------|------|
| read | 读取文件 |
| write | 创建/覆盖文件 |
| edit | 精确编辑文件 |

### 命令执行
| 工具 | 功能 |
|------|------|
| exec | 执行 shell 命令 |
| process | 管理后台进程 |

### 网络操作
| 工具 | 功能 |
|------|------|
| web_search | 搜索网页 |
| web_fetch | 获取网页内容 |
| browser | 浏览器自动化 |

### 通信操作
| 工具 | 功能 |
|------|------|
| message | 发送消息 |
| sessions_send | 跨会话发消息 |
| sessions_spawn | 创建子代理 |

### 设备操作
| 工具 | 功能 |
|------|------|
| nodes | 控制配对设备 |
| canvas | 展示内容 |
| tts | 语音合成 |

---

## 工具权限控制

```json
{
  "tools": {
    "allow": ["read", "web_search"],
    "deny": ["exec", "write", "edit"]
  }
}
```

---

## 工具 vs 技能

| 对比 | 工具 | 技能 |
|------|------|------|
| 来源 | 内置 | 外部安装 |
| 基础性 | 基础能力 | 高级功能 |
| 安装 | 自带 | 需要安装 |

---

## 八、志刚的实用场景

| 你想做的事 | 使用的工具 |
|-----------|-----------|
| 让我记住一件事 | write → 写入 MEMORY.md |
| 让我查资料 | web_search + web_fetch |
| 让我执行命令 | exec |
| 让我发消息 | message |
| 让我看文件 | read |

---

## 九、常用工具详解

### read — 读取文件
```
"帮我读取 MEMORY.md"
"看看这个文件里写了什么"
```

### write — 写入文件
```
"创建一个新笔记，内容是..."
"把这个内容保存到文件"
```

### exec — 执行命令
```
"运行这个命令"
"安装这个软件"
"查看系统状态"
```

### web_fetch — 获取网页
```
"帮我看看这个网页：https://xxx.com"
"抓取这个页面的内容"
```

### message — 发送消息
```
"发消息给 xxx"
"在群里发一条消息"
```
