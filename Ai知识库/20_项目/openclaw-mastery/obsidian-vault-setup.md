## 一、知识库整体架构

### 设计原则

1. **简单优先** — 先用起来，再慢慢优化
2. **按需扩展** — 不追求完美，够用就好
3. **AI 友好** — 让龙虾能帮你管理

## 四、工作流程

### 4.1 日常流程

```
早上
  ↓
打开日记 → 写今日任务
  ↓
工作中
  ↓
有想法 → 记到 Inbox 或对应笔记
  ↓
晚上
  ↓
回顾日记 → 整理 Inbox → 链接相关笔记
```

### 4.2 项目流程

```
新项目
  ↓
用模板创建项目笔记
  ↓
设置任务清单
  ↓
进展记录 → 定期更新
  ↓
项目完成 → 移到 Archive
```

### 4.3 知识流程

```
学新东西
  ↓
创建笔记 → 放到对应分类
  ↓
链接到相关笔记
  ↓
定期回顾 → 更新理解
```

## 五、和 OpenClaw 配合

### 龙虾可以帮你做的事

| 场景 | 你说 | 龙虾做 |
|------|------|--------|
| 创建日记 | "帮我创建今天的日记" | 生成日记文件 |
| 记录想法 | "帮我记一下这个想法..." | 写入对应笔记 |
| 整理笔记 | "帮我整理一下Inbox" | 分类和链接 |
| 搜索内容 | "我之前写的关于xxx的内容在哪？" | 搜索并展示 |
| 创建链接 | "帮我看看这几篇笔记有什么关联" | 分析并建议链接 |

### 配合要点

1. **笔记库位置** — 告诉龙虾你的笔记库路径
2. **使用模板** — 龙虾可以用模板创建笔记
3. **双向链接** — 龙虾可以帮你添加 `[[链接]]`
4. **定期整理** — 让龙虾帮你回顾和整理

## 六、开始行动

### 第一步：创建笔记库

1. 打开 Obsidian
2. 选择"创建新库"
3. 选择一个文件夹（比如 `~/Documents/obsidian-vault`）
4. 创建上述文件夹结构

### 第二步：创建模板

1. 在 Templates 文件夹创建模板文件
2. 复制上面的模板内容
3. 在设置中启用"模板"插件
4. 设置模板文件夹路径

### 第三步：创建索引

1. 创建 `Index.md`
2. 复制索引内容
3. 这是你进入知识库的第一页

### 第四步：开始记日记

1. 每天打开日记
2. 记录任务、想法、学习
3. 用 `[[链接]]` 连接相关笔记
