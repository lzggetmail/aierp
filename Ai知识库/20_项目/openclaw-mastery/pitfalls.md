# 🦞 OpenClaw 踩坑记录

> 踩过的坑，不要再踩第二次

---

## 安装坑

### 坑1：Node版本不对
- **现象**：安装失败或运行报错
- **原因**：需要 Node 22.16+ 或 Node 24
- **解决**：升级 Node 版本

### 坑2：权限问题
- **现象**：无法写入配置文件
- **原因**：权限不足
- **解决**：检查 `~/.openclaw` 目录权限

---

## 配置坑

### 坑3：渠道配置不生效
- **现象**：改了配置但没变化
- **原因**：没重启 Gateway
- **解决**：`openclaw gateway restart`

### 坑4：飞书对接失败
- **现象**：消息发不过去
- **原因**：App ID/App Secret 配置错误
- **解决**：检查飞书开放平台配置

---

## 记忆坑

### 坑5：AI"忘了"之前说过的话
- **现象**：昨天说的内容，今天AI不知道
- **原因**：
  1. 跨会话（另一个对话窗口）
  2. 没存进文件（只在对话中）
  3. 不同渠道（另一个飞书会话）
- **解决**：重要信息明确说"记录下来"

### 坑6：图片/富文本显示不了
- **现象**：收到"请升级客户端"提示
- **原因**：飞书富文本消息兼容性问题
- **解决**：让用户发文字内容，不要只发图片

---

## 多龙虾坑

### 坑7：多只龙虾串台
- **现象**：A龙虾知道了B龙虾的事
- **原因**：共享了 workspace 或 agentDir
- **解决**：每只龙虾用独立的 workspace

### 坑8：绑定规则不生效
- **现象**：消息没有路由到正确的龙虾
- **原因**：规则优先级或配置顺序问题
- **解决**：
  - 更精确的规则放前面
  - 用 `openclaw agents list --bindings` 检查

---

## 性能坑

### 坑9：响应越来越慢
- **现象**：龙虾反应迟钝
- **原因**：
  1. 会话历史太长
  2. 内存占用过高
- **解决**：清理旧会话或重启 Gateway

### 坑10：频繁掉线
- **现象**：渠道连接断开
- **原因**：网络问题或 token 过期
- **解决**：
  - `openclaw channels status --probe` 检查
  - 重新登录渠道

---

## 配对坑

### 坑11：配对命令输入两次导致失败 ⚠️ 志刚踩过的坑

- **现象**：配对失败，再也配不上
- **原因**：配对码是一次性的，输入两次破坏流程
- **错误做法**：
  ```bash
  openclaw pairing approve feishu JPD6D53R
  # 看起来"卡住"了，又输入一次
  openclaw pairing approve feishu JPD6D53R  # ❌ 报错！
  ```
- **正确做法**：只输入一次，耐心等待
- **解决**：
  ```bash
  openclaw channels logout --channel feishu
  openclaw channels login --channel feishu
  ```
