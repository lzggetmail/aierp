## 一、Obsidian 是什么？

**一句话**：本地优先的 Markdown 笔记软件，支持双向链接和知识图谱。

### 核心特点

| 特点 | 说明 |
|------|------|
| **本地存储** | 所有笔记都在你电脑上，不依赖云端 |
| **Markdown** | 纯文本格式，永远可读，不会被锁定 |
| **双向链接** | 笔记之间可以互相链接，形成知识网络 |
| **图谱视图** | 可视化你的知识关系网 |
| **插件生态** | 有几千个插件可以扩展功能 |
| **免费** | 个人使用完全免费 |

### 和其他笔记软件的区别

| 软件 | 存储位置 | 格式 | 双向链接 | 价格 |
|------|----------|------|----------|------|
| **Obsidian** | 本地 | Markdown | ✅ | 免费 |
| Notion | 云端 | 专有 | ❌ | 免费付费 |
| Evernote | 云端 | 专有 | ❌ | 付费 |
| Roam Research | 云端 | Markdown | ✅ | $15/月 |
| 印象笔记 | 云端 | 专有 | ❌ | 付费 |

## 二、安装和配置

### 2.1 下载安装

1. 访问 https://obsidian.md
2. 下载对应系统版本（Windows/Mac/Linux）
3. 安装

### 2.2 创建笔记库（Vault）

1. 打开 Obsidian
2. 点击"创建新库"
3. 选择一个文件夹作为笔记库存放位置
4. 这个文件夹就是你的"第二大脑"

### 2.3 基本配置

**设置 → 编辑器**
- 打开"智能折叠"
- 设置默认字体大小

**设置 → 文件与链接**
- 设置"新建笔记的存放位置"
- 打开"自动更新内部链接"

## 三、基本操作

### 3.1 创建笔记

- 快捷键：`Ctrl/Cmd + N`
- 或点击左侧"新建笔记"按钮

### 3.2 双向链接（核心功能）

```markdown
# 今天学到了什么

我学习了 [[OpenClaw]] 和 [[Obsidian]] 的组合使用。

[[OpenClaw]] 是一个 AI 助手平台。
```

**效果**：
- `[[OpenClaw]]` 会变成可点击的链接
- 点击后跳转到 OpenClaw 笔记
- OpenClaw 笔记的"反向链接"面板会显示这篇文章

### 3.3 标签

```markdown
#openclaw #学习 #ai
```

- 用 `#` 开头
- 可以在标签面板看到所有标签
- 点击标签可以搜索所有相关笔记

### 3.4 图谱视图

- 快捷键：`Ctrl/Cmd + G`
- 或点击"关系图谱"按钮
- 可视化你的知识网络

## 四、常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + N` | 新建笔记 |
| `Ctrl/Cmd + G` | 打开图谱 |
| `Ctrl/Cmd + O` | 快速打开笔记 |
| `Ctrl/Cmd + P` | 命令面板 |
| `Ctrl/Cmd + [` | 后退 |
| `Ctrl/Cmd + ]` | 前进 |
| `[[` | 插入链接（输入笔记名） |

## 五、推荐插件

### 5.1 核心插件（自带）

- **模板**：快速创建标准化笔记
- **日记**：每天自动创建日记笔记
- **反向链接**：查看哪些笔记链接到当前笔记
- **出链**：查看当前笔记链接到哪些笔记

### 5.2 社区插件（推荐）

| 插件 | 功能 |
|------|------|
| **Dataview** | 查询和展示笔记数据（必装） |
| **Templater** | 高级模板自动化 |
| **Calendar** | 日历视图 |
| **Tasks** | 任务管理 |
| **Kanban** | 看板视图 |
