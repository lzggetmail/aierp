## 一、界面布局结构（三栏式）

### 左侧栏：Agent 列表与会话流

- **核心展示**：所有 AI 角色（小蜜 - 运营、小舟、小工 - 工程、小艺 - 设计、小投_投资助手、小数 - 数据、小财_财务等）
- **会话逻辑**：类似 IM 聊天列表，实时推送 Agent 最新消息
  - 任务完成反馈（如「Subagent xiaomi finished 已完成返工任务」）
  - 模型升级通知
  - 思考等级配置（如「Current thinking level: medium」）
- **设计价值**：让管理者直观掌握各 Agent 动态，形成清晰的「虚拟团队」感知

### 中间栏：功能模块入口

- **垂直功能分组**：
  - 全局视图：`All`
  - 业务场景：`内容运营`、`开发`、`设计美学`、`数据分析`、`财务分析`
  - 专项工具：`投资思考`、`模型算力`
- **交互逻辑**：点击模块后，自动路由至对应工作流
- **设计价值**：贴合真实办公场景，降低用户学习成本

### 右侧栏：群聊 / 任务详情区

- **群聊载体**：以「船长的无人公司」为核心协作群
- **内容展示**：富文本格式的任务输出
- **设计价值**：多 Agent 协作结果统一沉淀，形成可追溯、可复用的工作成果

## 三、核心设计亮点

| 设计点 | 具体实现 | 参考价值 |
|--------|----------|----------|
| **角色化 Agent 设计** | 每个 Agent 对应真实岗位 | 降低协作复杂度，符合人类团队协作认知 |
| **思考等级动态控制** | off/minimal/low/medium/high | 平衡算力成本与输出质量 |
| **任务闭环可视化** | 完成后自动推送结果 | 提升流程透明度，避免任务遗漏 |
| **场景化功能路由** | 按业务场景分组入口 | 用户无需理解底层技术 |
| **聊天式交互范式** | 基于 IM 界面 | 大幅降低学习成本 |

## 四、底层架构逻辑

### 架构分层

```
┌───────────────── 前端层 ─────────────────┐
│  企业IM客户端（复用现有）/三栏界面       │
└─────────────────┬──────────────────────┘
                  │ 消息路由/权限控制
┌─────────────────▼──────────────────────┐
│  OpenClaw Gateway（核心调度层）         │
│  功能：请求解析→路由分发→结果聚合       │
└─────────────────┬──────────────────────┘
                  │ 任务分配/状态同步
┌─────────────────▼──────────────────────┐
│  Agent执行层（多Agent集群）             │
│  组件：运营Agent/工程Agent/设计Agent等   │
└─────────────────┬──────────────────────┘
                  │ 数据交互/算力调用
┌─────────────────▼──────────────────────┐
│  资源层（模型/数据/算力）                │
│  组件：大模型集群/数据库/服务器资源      │
└────────────────────────────────────────┘
```

### 关键技术逻辑

1. **路由分发**：Gateway 解析请求关键词，匹配对应职能 Agent
2. **Agent 隔离性**：各 Agent 拥有独立会话空间、数据权限与算力配额
3. **状态同步**：基于 WebSocket 实现实时状态同步
4. **算力调度**：根据思考等级配置，动态分配模型调用次数

## 六、工作流程

```
1. 手机打开 Telegram
      ↓
2. 进入工作群组/选择员工
      ↓
3. 语音输入提需求
      ↓
4. Agent 接收任务，思考（thinking）
      ↓
5. 形成结构化消息
      ↓
6. 在设定时间执行
      ↓
7. 晨间日报推送结果
```

## 八、对志刚的启发

### 如果要设计自己的系统

1. **角色设计**
   - 需要哪些"虚拟员工"？
   - 每个 Agent 的职责边界在哪？

2. **知识管理**
   - 每个 Agent 的"文件夹"应该包含什么？
   - 如何让 Agent 积累经验？

3. **工作流程**
   - 日常工作有哪些可以交给 Agent？
   - Agent 之间如何协作？

4. **界面选择**
   - 用 Telegram 还是飞书？
   - 手机端还是电脑端为主？
