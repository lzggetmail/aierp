### 2. Tavily 搜索技能

**安装**：
```bash
skillhub install tavily-search-skill
```

**配置**：
- 需要环境变量 `TAVILY_API_KEY`
- API Key 来源：https://app.tavily.com/api-keys

**使用**：
```bash
node scripts/search.mjs "查询内容" -n 5
```

**测试结果**：搜索 "OpenClaw" 成功返回 Wikipedia、DigitalOcean 等来源

## 心得

1. **工程化管理很重要** - 用文件夹结构管理学习进度，比散落在各处更清晰
2. **技能安装很简单** - `skillhub install` 一条命令搞定
3. **配置是关键** - 很多功能需要配置环境变量才能工作
4. **心跳 vs 定时** - 心跳是被动检查，定时是主动推送
   - 心跳：用户触发时检查
   - 定时：系统自动触发（如每天8:00晨间简报）
5. **Markdown 只是"衣服"** - AI 理解的是语义，不是语法
   - 符号是为了让人看着舒服
   - AI 读的是"意思"，不是"格式"
