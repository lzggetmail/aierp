## 动态记录

### 2026-03-22

**重大新闻：钉钉悟空发布** 🦈

3月17日，钉钉正式发布"悟空"企业级 AI 原生工作平台，这是**全球首个企业级 Agent 平台**。

**核心定位**：
- "to C 千问，to B 悟空" — 阿里 AI 双强格局
- 与 OpenClaw（龙虾）不同，悟空专为企业级安全设计
- 开启全球邀测，同步进军海外市场

**技术架构**：
- 钉钉全量底层代码重写，GUI → CLI/API 化
- 所有办公能力拆解为原子化命令行模块
- AI 可直接调用，不需要模拟人类操作

**安全体系（六层）**：
1. 双层规则体系
2. 统一身份认证（钉钉账号）
3. 专属沙箱
4. Skill 生态安全管控
5. 专属模型
6. 网络代理

**Skill 生态**：
- 推出 AI 能力市场
- 全面兼容开源 Skill 体系
- 目标：全球最大 toB Skill 市场
- OPT（一人团队）十大行业解决方案

**对 OpenClaw 的启示**：
- 企业级 Agent 市场正式爆发
- 安全和权限管理是关键差异点
- Skill 生态是未来竞争焦点
- 个人级 Agent（OpenClaw）vs 企业级 Agent（悟空）并行发展

### 2026-03-22 晚间更新：三巨头格局形成

**腾讯 QClaw 发布**（3月20日）：
- 腾讯定制版"龙虾"
- 马化腾在财报会上表示："龙虾应用能让 AI 落地到各种丰富场景"
- 接入 QQ、企业微信、**微信小程序**
- WorkBuddy 企业版：全场景 AI 智能体，兼容 OpenClaw 生态
- 上线一周内服务压力触发十倍扩容

**三巨头格局**：
| 公司 | 产品 | 入口 | 云服务 |
|------|------|------|--------|
| 阿里 | 悟空 | 钉钉 | 阿里云 |
| 字节 | 飞书aily | 飞书/抖音/豆包 | 火山引擎 |
| 腾讯 | QClaw + WorkBuddy | 微信/QQ/企业微信 | 腾讯云 |

**核心商业逻辑**：
> 大厂从"卖模型"转向掌控 Token 全生态链路
> 谁能让 Agent 钻进 14 亿用户的聊天框，谁就能定义下一个时代的入口
> 利用 OpenClaw 吸引用户，并将他们绑定在自家"电网"中

**Token 数据**：
- 2024年初：中国日均 Token 消耗 1000亿
- 2025年中：30万亿
- 2026年2月：180万亿
- 90% Token 消耗来自"养虾"

**对志刚的机会**：
- 三巨头竞争 = 开发者红利期
- 飞书开源 OpenClaw 插件 = 可直接对接
- 企业级安全合规 = 差异化优势
- Token 消耗激增 = 云服务/培训市场机会
