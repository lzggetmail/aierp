# 孙总销售管理技巧拆解

> 基于AI总裁项目会议记录分析
> 时间：2026年3月7日、3月11日

---

## 难点一：团队成员不认可产品（99.9%被挂名）

### 症状
- 团长"不知道自己在干什么"
- "被挂名的，不是自己想当的"
- 对产品没信心

### 孙总的应对方法

| 方法 | 具体做法 | 值得学习 |
|------|----------|----------|
| **不谈产品价值** | 不解释产品好不好用，直接跳过 | ✅ 避开弱点 |
| **谈"使命"和"信念"** | "未来20年必须打赢这一仗" | ✅ 用宏大叙事替代产品信心 |
| **制造愧疚感** | "99.9%是被挂名的" | ✅ 让人觉得"我不够努力" |
| **服从性测试** | 改微信名、现场检查 | ✅ 用小动作筛选配合的人 |

### 核心逻辑
```
产品信心不足 → 不谈产品 → 谈使命/状态 → 让人先动起来
```

### 借鉴要点
- 如果产品有短板，不要硬解释
- 用其他价值（使命、机会、成长）来弥补
- 先让人行动，再建立信心

## 难点二：客户质疑产品功能

### 症状（3月7日会议暴露）
- 客户问"这个功能能不能解决我的问题？"
- 推荐官回答不上来
- 容易被客户"带偏"

### 孙总的应对方法

| 方法 | 具体做法 | 值得学习 |
|------|----------|----------|
| **不纠结细节** | "不要跟客户纠结问题" | ✅ 避免陷入细节辩论 |
| **吸收问题** | "所有问题就是吸收，不要解决问题" | ✅ 把问题变成"未来规划" |
| **抛回来** | "把问题抛回来，说下次升级解决" | ✅ 不承诺，但不拒绝 |
| **不浪费时间** | "我不愿意陪那个纠结的人聊1小时" | ✅ 筛选客户，不做无效沟通 |

### 话术模板
```
客户：这个功能能解决我的XX问题吗？

孙总式回答：
"这个问题很好，我们先记录下来。
我们现在搭的是一个大模型，整个全域都能进来。
你先站进来，后面我们会针对这个行业做升级。
你现在进来就是最早的，后面功能会越来越多。"
```

### 核心逻辑
```
客户质疑 → 不辩论 → 吸收问题 → 推给未来 → 先让人进来
```

### 借鉴要点
- 不要跟客户辩论产品细节
- 把问题转化为"未来规划"
- 用"大方向"覆盖"小问题"
- 筛选愿意相信的人，过滤纠结的人

## 难点三：团队成员不知道怎么做（没方法）

### 症状
- "有方向，但没目标，没打法"
- "不知道怎么去打"
- 推荐官质量参差不齐

### 孙总的应对方法

| 方法 | 具体做法 | 值得学习 |
|------|----------|----------|
| **极度简化目标** | 只说两件事：首席推荐官 + 企业注册 | ✅ 不让人困惑 |
| **第一步最简单** | "改微信名"——傻瓜都能做 | ✅ 降低行动门槛 |
| **不讲复杂方法** | 不教销售技巧，只教"态度" | ⚠️ 短期有效，长期有风险 |
| **现场检查执行** | 倒计时、相互检查 | ✅ 确保动作落实 |

### 核心逻辑
```
方法太复杂 → 团队不会做 → 简化到最简单 → 先动起来再说
```

### 借鉴要点
- 目标要简单到傻瓜都能执行
- 第一步门槛要低
- 现场检查，确保执行
- 但长期要补充具体方法

## 难点四：团队士气低落

### 症状
- 60%团长没来参会
- 来的人也"被挂名"
- 数据不好（41家企业，目标50+）

### 孙总的应对方法

| 方法 | 具体做法 | 值得学习 |
|------|----------|----------|
| **开场调情绪** | 先鼓掌、先认同 | ✅ 建立正向氛围 |
| **强调"第一站"** | "这只是第一站，不是最后一站" | ✅ 降低心理压力 |
| **肯定已有成果** | "41个已经不错了，还能冲到50+" | ✅ 用小成功激励 |
| **不提负面** | 不说"60%没来"，只说"来的都是相信的" | ✅ 聚焦正面 |

### 核心逻辑
```
士气低落 → 调情绪 → 肯定成果 → 降低压力 → 聚焦当下
```

### 借鉴要点
- 开会前先调情绪，不要一上来就讲问题
- 用小成功激励，不要只看差距
- 降低心理压力，"只是第一站"
- 聚焦正面，过滤负面

## 难点五：激励机制不清晰

### 症状（3月7日会议暴露）
- "我带人来，我也是推荐，他也是推荐，我有啥优势？"
- 团队成员觉得"白干"

### 孙总的应对方法

| 方法 | 具体做法 | 值得学习 |
|------|----------|----------|
| **平级起步** | "现在大家都是平级的" | ✅ 降低心理落差 |
| **升迁路径** | "卖三套产品后升代理" | ✅ 给人盼头 |
| **利益绑定** | "你带的人会放到你团队下面" | ✅ 长期利益绑定 |
| **不解释太多** | "再讲就心里不平衡了" | ✅ 适可而止 |

### 核心逻辑
```
激励机制不清 → 简化解释 → 给升迁路径 → 利益绑定 → 不纠结细节
```

### 借鉴要点
- 机制要简单，不要复杂
- 给人"上升"的盼头
- 用长期利益绑定
- 不要解释太细，越解释越乱

## 难点六：内部人员不如外部人员

### 症状（3月7日会议暴露）
- "外面团队带进来的，比内部的人了解的还多"
- 内部培训不到位

### 孙总的应对方法

| 方法 | 具体做法 | 值得学习 |
|------|----------|----------|
| **不纠结原因** | 不分析为什么内部不行 | ⚠️ 没解决问题 |
| **利用外部力量** | 外部团队带人来也行 | ✅ 不拘一格 |
| **快速筛选** | 谁能干谁上 | ✅ 结果导向 |

### 借鉴要点
- 不纠结"为什么"，聚焦"怎么办"
- 谁能出结果就用谁
- 但长期要解决内部培训问题

## 孙总的核心方法论总结

### 1. 简化原则
> 能不讲就不讲，能简单就简单

- 目标简化：只说两件事
- 动作简化：改微信名
- 话术简化：不纠结细节

### 2. 情绪先行
> 先调情绪，再讲内容

- 开场鼓掌
- 肯定成果
- 制造使命感
- 不提负面

### 3. 服从测试
> 用小动作筛选配合的人

- 改微信名
- 现场检查
- 倒计时

### 4. 问题吸收
> 不解决问题，吸收问题

- 不辩论
- 推给未来
- 筛选客户

### 5. 结果导向
> 谁能出结果用谁

- 不问原因
- 不纠结过程
- 只看数据

## 值得学习的技巧清单

### ✅ 强烈推荐学习

| 技巧 | 场景 | 怎么用 |
|------|------|--------|
| **开场控场** | 会议、培训 | 先收手机、立规矩、调情绪 |
| **目标简化** | 团队管理 | 只说一件事，不说十件事 |
| **服从性测试** | 筛选配合的人 | 用小动作测试，不配合的直接过滤 |
| **问题吸收** | 客户质疑 | 不辩论，吸收问题，推给未来 |
| **情绪先行** | 动员、激励 | 先鼓掌、先肯定，再讲内容 |

### ⚠️ 谨慎使用

| 技巧 | 风险 | 适用场景 |
|------|------|----------|
| **不谈产品细节** | 长期会失去信任 | 产品有短板时，短期可用 |
| **宏大叙事** | 听起来假 | 需要打鸡血时，但不能长期 |
| **不教具体方法** | 团队成长慢 | 初期可用，后期要补充 |

### ❌ 不推荐学习

| 技巧 | 问题 |
|------|------|
| **用管理弥补产品缺陷** | 治标不治本 |
| **割韭菜式销售** | 长期不可持续 |

## 对志刚的启示

### 如果你要做AI培训/咨询

**可以用的技巧：**

1. **开场控场**
   - 先收手机
   - 立规矩
   - 先鼓掌调情绪

2. **目标简化**
   - 今天只学一招
   - 不要讲太多

3. **服从性测试**
   - 先让人做一件小事
   - 筛选愿意配合的人

4. **问题吸收**
   - 客户问细节问题，先记录
   - 说"这个问题很好，我们后面会讲"

5. **情绪先行**
   - 先肯定学员
   - 先建立信心
   - 再讲内容

### 但要注意

- 产品/服务本身要有价值
- 不能只靠话术
- 长期要建立真正的能力
