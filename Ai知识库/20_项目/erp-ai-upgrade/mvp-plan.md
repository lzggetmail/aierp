> 状态：规划中

## 一、项目背景

### 产品现状

| 项目 | 说明 |
|------|------|
| **产品** | 老同事开发的 Delphi ERP（CS 架构） |
| **历史** | 十多年积累，在垂直领域有优势 |
| **问题** | 太传统、太重、不适应未来趋势 |
| **目标** | AI 升级、适应 OPT（一人公司）趋势 |

### 现实约束

| 约束 | 说明 |
|------|------|
| **技术** | 薄弱，不能和大厂比 |
| **成本** | 有限，不能烧钱 |
| **品牌** | 有限，客户认知度低 |
| **客户** | "不见兔子不撒鹰"，要看到结果才买单 |

---

## 二、解决方案：轻量化 AI ERP

### 核心理念

| 理念 | 说明 |
|------|------|
| **轻量化设计** | 不追求大而全，追求小而美 |
| **先上马后优化** | 不是完美才上线，而是上线再优化 |
| **渐进式升级** | 朝着悟空的最终形态迈进 |
| **AI 弥补** | 用大模型能力弥补数据不严谨 |

### 五大升级方向

#### 1. 解绑数据库约束

| 改变 | 说明 |
|------|------|
| 解除字段约束 | 减少数据输入限制 |
| 放开表格约束 | 允许数据灵活 |

#### 2. 简化审批流程

| 改变 | 说明 |
|------|------|
| **以前** | 十级审批 |
| **现在** | 一层，最多两层 |
| **未来** | Chat 方式，大模型处理审批 |

#### 3. 前端重新开发

| 改变 | 说明 |
|------|------|
| CS 架构 | Web 架构 |
| 客户端安装 | 浏览器直接访问 |

#### 4. AI 化

| 能力 | 说明 |
|------|------|
| **Chat 审批** | 用对话方式完成审批 |
| **AI 弥补** | 大模型处理数据不严谨问题 |
| **智能辅助** | 降低操作门槛 |

#### 5. 渐进式升级

| 阶段 | 内容 |
|------|------|
| **第一阶段** | AI 特性展现、快速上线 |
| **第二阶段** | 数据库优化、迭代升级 |
| **未来** | 迁移到 MongoDB 等非结构化数据库 |

### 核心公式

**轻量化 AI ERP = Web 前端 + 解绑数据库 + 简化流程 + AI 弥补**

## 三、MVP 验证计划

### 目标客户

| 项目 | 说明 |
|------|------|
| **对象** | 朋友的工厂 |
| **规模** | 约 100 人 |
| **类型** | 小企业（中小微企业目标客户） |

### 验证策略

| 策略 | 说明 |
|------|------|
| **既有 ERP** | 快速部署（不需要重新开发） |
| **前端优化** | 只做少量页面，让 AI 可见 |
| **时间短** | 快速验证，边做边调 |

### AI 可见化设计

#### 1. 输入方式

| 传统 | AI 化 |
|------|-------|
| 复杂表单 | 简单输入窗口 |
| 多字段填写 | AI 辅助填充 |
| 严格约束 | 容错处理 |

#### 2. 查询方式

| 传统 | AI 化 |
|------|-------|
| 多级菜单 | Chat 对话 |
| 记住路径 | 自然语言提问 |
| 复杂操作 | 一句话解决 |

#### 3. 任务分配

| 传统 | AI 化 |
|------|-------|
| 手动分配 | AI 智能分配 |
| 多步操作 | Chat 下达指令 |
| 人工跟进 | AI 自动提醒 |

### 核心原则

| 原则 | 说明 |
|------|------|
| **AI 可见** | 每个操作都要体现 AI 的存在 |
| **对比明显** | 传统 vs AI，一眼看出差别 |
| **快速见效** | 不需要培训，上手就用 |

## 八、核心洞察：AI 顾问型 ERP

### 老板真正想要的

| 形式上的 AI | 真正的价值 AI |
|-------------|---------------|
| AI 问答、聊天 | 发现企业潜在问题 |
| AI 输入、查询 | 降本增效 |
| 炫酷功能 | 帮老板省钱、赚钱 |

**老板要的不是"AI"，而是"价值"。**

### 类比：财务顾问

| 角色 | 能力 |
|------|------|
| **财务人员** | 做账、报表、执行 |
| **财务顾问** | 发现财务问题、诊断 |
| **AI 顾问** | 从繁杂数据中发现老板关心的问题 |

**核心洞察：企业有财务人员，但老板还是需要顾问。AI 可以成为顾问。**

### AI 顾问的价值

| 能力 | 说明 |
|------|------|
| **发现潜在问题** | 从繁杂数据中挑出老板关心的问题 |
| **人力评估** | 哪些岗位饱和度够不够？ |
| **人力预测** | 减产/增产要不要加人/减人？ |
| **业财一体** | 老板有账看不懂，AI 帮他看 |

### 底层逻辑

```
老板的痛点：
- 有数据（财务账、人力数据、业务数据）
- 但看不懂问题
- 需要顾问帮他发现
        ↓
传统解决方案：
- 请顾问（贵、不一定靠谱）
        ↓
AI 解决方案：
- AI 从繁杂数据中发现问题
- 不用请顾问，AI 就是顾问
- 更便宜、更及时、更全面
        ↓
价值：
- 老板看到"兔子"（问题）
- 愿意付费
```

### 产品定位

**以前**：AI 升级的 ERP
**现在**：AI 顾问型 ERP

**对老板说的话**：
- "你有财务账，但看不懂问题"
- "AI 帮你从繁杂数据中发现问题"
- "不用请顾问，AI 就是顾问"

### 核心公式

**AI ERP 的真正价值 = AI 顾问**

| 传统 ERP | AI 顾问型 ERP |
|----------|---------------|
| 记录数据 | 发现问题 |
| 执行流程 | 诊断企业 |
| 被动响应 | 主动预警 |
| 老板看报表 | 老板看问题 |
