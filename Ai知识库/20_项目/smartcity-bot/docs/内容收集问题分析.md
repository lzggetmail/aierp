### 问题3: 只有被动收集，没有主动抓取

**当前机制**:
```
用户发消息 → 分析内容 → 判断是否有价值 → 收集
```

**问题**:
- 依赖群内用户主动分享
- 没有主动爬取外部资源
- 没有定时抓取行业网站
- 没有集成知识星球等内容源

**当前状态**:

- 没有定时任务调度

### 4. 实现智能过滤

```python
class SmartFilter:
    """智能内容过滤"""
    
    def __init__(self):
        # 价值评分规则
        self.value_rules = {
            "报告类": {
                "keywords": ["白皮书", "研究报告", "市场分析"],
                "min_score": 8
            },
            "政策类": {
                "keywords": ["政策", "标准", "规范"],
                "min_score": 7
            },
            "案例类": {
                "keywords": ["案例", "实践", "落地"],
                "min_score": 6
            }
        }
    
    def calculate_value_score(self, text: str) -> int:
        """计算内容价值分数（1-10）"""
        score = 0
        
        # 包含关键词数量
        keyword_count = sum(1 for kw in self.all_keywords if kw in text)
        score += min(keyword_count, 3)
        
        # 包含链接
        if "http" in text:
            score += 2
        
        # 包含数据
        if re.search(r'\d+%|\d+亿|\d+万', text):
            score += 2
        
        # 来源权威性
        if any(brand in text for brand in ["德勤", "麦肯锡", "华为"]):
            score += 2
        
        # 长度适中
        if 100 < len(text) < 1000:
            score += 1
        
        return min(score, 10)
```
