# 图片素材分类说明

## 分类标准

### 1. 流程图
- **业务流程**: 业务操作流程、审批流程
- **工作流程**: 日常工作流程、协作流程
- **决策流程**: 决策树、判断流程
- **关键词**: 流程、process、flow、workflow、步骤、决策

### 2. 架构图
- **系统架构**: IT系统架构、软件架构
- **技术架构**: 技术栈、技术选型
- **组织架构**: 组织结构、团队架构
- **关键词**: 架构、architecture、系统、system、框架、framework

### 3. 数据可视化
- **图表**: 柱状图、折线图、饼图等
- **仪表盘**: 数据大屏、监控面板
- **信息图**: 数据呈现、统计图表
- **关键词**: 图表、chart、可视化、visualization、dashboard、数据

### 4. 思维导图
- **知识图谱**: 知识结构、概念关系
- **概念图**: 概念映射、知识体系
- **脑图**: 思维整理、创意发散
- **关键词**: 思维导图、mindmap、脑图、heptabase、画布

### 5. 信息图表
- **统计图**: 数据统计、对比分析
- **对比图**: 方案对比、优劣对比
- **时间线**: 时间轴、演进路线
- **关键词**: 信息图、infographic、对比、时间线、roadmap

### 6. UI界面
- **产品界面**: 产品截图、界面展示
- **原型图**: 设计原型、交互设计
- **设计稿**: UI设计、视觉设计
- **关键词**: 界面、interface、UI、原型、prototype、截图

### 7. 其他
- 无法明确分类的图片
- 待人工审核的图片

## 自动分类规则

### 分类逻辑
1. 分析图片关联的主题标题和描述文本
2. 匹配关键词库，计算匹配度
3. 选择匹配度最高的分类
4. 如果无匹配，归入"其他"分类

### 示例
```
主题: "凯捷研究院：走进高管层——人工智能如何悄然重塑高管决策"
图片: 决策流程图.png
-> 分类结果: 流程图

主题: "德勤：技术趋势2026"
图片: 系统架构设计.jpg
-> 分类结果: 架构图

主题: "FT 数据可视化词典"
图片: 图表示例.png
-> 分类结果: 数据可视化
```

## 使用方法

### Node.js 下载器
```bash
cd zsxq-downloads
node zsxq-downloader.js
# 图片会自动分类到对应目录
```

### Python 分类器
```python
from utils.image_classifier import ImageClassifier

classifier = ImageClassifier("zsxq-downloads/数字化解决方案知识库/图片素材")

# 单个图片分类
result = classifier.classify_and_move(
    "images/example.png",
    context="AI决策流程图"
)

# 批量分类
results = classifier.batch_classify("images/")
```

## 手动调整

如果自动分类不准确，可以手动移动：

```bash
# 移动到正确分类
mv 图片素材/其他/xxx.png 图片素材/流程图/

# 或使用 Python 脚本
python -m utils.image_classifier --move \
  --source "图片素材/其他/xxx.png" \
  --target "流程图"
```

## 统计信息

查看各分类的图片数量：
```bash
cd 图片素材
for dir in */; do
  count=$(find "$dir" -type f | wc -l)
  echo "$dir: $count 张"
done
```
