### 1. 收集新文章


- 自动保存到 `tech_documents/rss/`

---

### 2. 审核文章

#### 方式A: 自动审核（推荐）

自动通过高可信度文章（≥8分）：

```bash
python3 -c "
from crawler.article_synchronizer import ArticleSynchronizer
syncer = ArticleSynchronizer()
syncer.auto_approve_and_sync(min_credibility=8)
"
```

#### 方式B: 交互式审核

逐个审核文章：

```bash
python3 crawler/review_interface.py

# 选项:
# 1. 收集新文章并审核
# 2. 查看待审核文章
# 3. 交互式审核 (y通过/n拒绝/s跳过)
# 4. 自动通过高可信度
# 5. 查看统计
# 6. 导出已通过文章
```

#### 方式C: API调用

```python
from crawler.article_manager import TechArticleManager

manager = TechArticleManager()

# 通过单篇文章
manager.approve_article(article_id, reviewer="user")

# 拒绝文章
manager.reject_article(article_id, reason="内容不相关")

# 获取待审核列表
pending = manager.get_pending_articles(limit=50, min_credibility=6)
```

---

### 3. 同步到docs目录

将审核通过的文章同步到 `docs/` 目录：

```bash
python3 -c "
from crawler.article_synchronizer import ArticleSynchronizer
syncer = ArticleSynchronizer()
stats = syncer.sync_approved_articles()
print(f'同步完成: {stats}')
"
```

**结果**:
- 生成 Markdown 文件
- 自动分类到对应目录
- 更新 README 索引

## 🔄 定时任务

### 每小时收集

```python
# scheduler/tasks.py
from apscheduler.schedulers.background import BackgroundScheduler

scheduler = BackgroundScheduler()

@scheduler.task('cron', hour='*')
def collect_tech_articles():
    """每小时收集技术资料"""
    from crawler.rss_api_collector import RSSTechCollector
    from crawler.article_manager import TechArticleManager
    
    # 收集
    collector = RSSTechCollector()
    articles = collector.collect_all()
    
    # 去重入库
    manager = TechArticleManager()
    stats = manager.batch_add_articles([...])
    
    # 自动通过高可信度
    if stats['new'] > 0:
        from crawler.article_synchronizer import ArticleSynchronizer
        syncer = ArticleSynchronizer()
        syncer.auto_approve_and_sync(min_credibility=8)

scheduler.start()
```

## 🔧 故障排查

### 问题1: 收集失败

```bash
# 检查网络连接
curl -I https://www.infoq.cn/feed

# 检查RSS格式
python3 -c "import feedparser; print(feedparser.parse('https://www.infoq.cn/feed'))"
```

### 问题2: 数据库锁定

```bash
# 检查数据库状态
sqlite3 tech_documents/articles.db "PRAGMA integrity_check;"

# 备份数据库
cp tech_documents/articles.db tech_documents/articles.db.bak
```

### 问题3: 同步失败

```bash
# 检查目录权限
ls -la docs/

# 手动创建目录
python3 -c "from crawler.article_synchronizer import ArticleSynchronizer; ArticleSynchronizer()._ensure_directories()"
```
