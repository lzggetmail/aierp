## 使用方法

### Python API
```python
from utils.zsxq_manager import ZsxqManager

# 初始化管理器
manager = ZsxqManager()

# 获取所有星球
groups = manager.get_groups()

# 获取主题列表
topics = manager.get_topics("88855248152252", count=20)

# 同步内容
stats = manager.sync_group_content(
    group_id="88855248152252",
    output_dir="zsxq-downloads/数字化解决方案知识库"
)
```

### 命令行工具
```bash
# 同步所有星球内容
python -m utils.zsxq_manager --sync-all

# 同步指定星球
python -m utils.zsxq_manager --sync 88855248152252

# 查看星球列表
python -m utils.zsxq_manager --list-groups
```

## 自动化集成

### 定时同步
在 `config/schedule.json` 中配置:
```json
{
  "zsxq_sync": {
    "enabled": true,
    "cron": "0 2 * * *",
    "groups": ["88855248152252", "51128488121484"]
  }
}
```

### 飞书同步
- 自动上传到飞书知识库
- 按分类创建文件夹
- 生成知识索引
