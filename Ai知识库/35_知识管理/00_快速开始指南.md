# 知识库快速开始指南

> 欢迎使用个人知识管理系统！本指南将帮助您快速上手。

## 🎯 这是什么？

这是一个基于 Obsidian + Claudian 的**第二大脑系统**，帮助您：
- 📚 **系统化管理知识**：用统一的方法组织和存储知识
- 🔗 **建立知识网络**：通过双向链接连接相关概念
- 🤖 **AI协作学习**：让Claudian帮助您检索和组织知识
- 📈 **持续成长**：通过结构化积累提升个人能力

---

## 🚀 5分钟快速上手

### 第1步：了解核心概念

#### 什么是模板？
模板是标准化的笔记格式，确保您每次记录都包含关键信息。

我们有5类核心模板：
1. **模板-Agent开发笔记**：记录Agent开发过程
2. **模板-技术概念笔记**：深入理解技术概念
3. **模板-项目经验笔记**：总结项目经验教训
4. **模板-SOP文档**：记录标准化流程
5. **模板-方法论笔记**：学习各种方法论

#### 什么是MOC？
MOC（Map of Content）是"知识地图"，帮助您：
- 快速找到相关主题的内容
- 了解某个主题的全景视图
- 作为探索知识库的起点

我们的MOC系统：
- **MOC-AI开发知识地图**：主入口，整体知识体系
- **MOC-Agent开发全流程**：Agent开发专题
- **MOC-知识管理系统**：知识管理方法
- **MOC-学习方法论**：学习方法合集

---

### 第2步：创建您的第一个笔记

#### 场景：您刚学了一个新概念（例如"Agent"）

1. **打开模板**：
   - 在 `35_知识管理/00_模板系统/` 找到 `模板-技术概念笔记.md`
   - 复制其内容

2. **创建新笔记**：
   - 在合适的位置创建新文件，命名为 `Agent定义.md`
   - 粘贴模板内容

3. **填写frontmatter**：
```yaml
---
type: concept
tags: [概念, AI, Agent]
category: 知识点
domain: AI
difficulty: 入门
importance: ⭐⭐⭐
created: 2026-03-25
last_updated: 2026-03-25
mastery_level: 理解
related: []
---
```

4. **填写内容**：
   - 概述：用您的话定义Agent
   - 核心要点：列出3-5个关键点
   - 实际应用：举几个例子
   - 建立链接：链接到相关概念

#### 提示：
- 使用 `[[文件名]]` 格式创建双向链接
- 标签使用英文，已有标签优先复用
- 定期更新 `last_updated` 字段

---

### 第3步：探索知识库

#### 从MOC开始探索

1. **打开主MOC**：
   - 查看 `MOC-AI开发知识地图.md`
   - 了解整体知识体系

2. **选择感兴趣的领域**：
   - Agent开发 → `MOC-Agent开发全流程.md`
   - 知识管理 → `MOC-知识管理系统.md`
   - 学习方法 → `MOC-学习方法论.md`

3. **跟随链接探索**：
   - 点击双链接查看相关笔记
   - 使用图谱视图查看知识网络

---

### 第4步：使用Claudian查询知识

#### Claudian是什么？

Claudian是Obsidian插件，让AI能够：
- 读取您的知识库
- 搜索相关内容
- 组织和总结信息
- 生成个性化方案

#### 如何使用Claudian

1. **安装Claudian**（如果还没安装）：
   - 在Obsidian设置中启用第三方插件
   - 搜索并安装Claudian
   - 配置API密钥

2. **向知识库提问**：
   ```
   帮我找出Agent开发的所有SOP文档
   总结知识管理中的核心方法论
   我应该从哪里开始学习Agent开发？
   ```

3. **让Claudian组织知识**：
   ```
   我要开发一个文件处理的Agent，
   请从我的知识库中找出相关的SOP、
   注意事项、工具选择建议，并组织成开发方案
   ```

## 💡 常见问题

### Q1: 我应该从哪里开始？

**A**: 从当前正在学习或工作的内容开始：
- 如果在学Agent开发 → 用"模板-Agent开发笔记"
- 如果在学新概念 → 用"模板-技术概念笔记"
- 如果在做项目 → 用"模板-项目经验笔记"

### Q2: 需要填写所有模板字段吗？

**A**: 不需要。模板是参考，不是强制：
- 必填字段：type, tags, created, last_updated
- 其他字段：根据需要填写
- 可以简化模板，移除不需要的部分

### Q3: 如何处理已有笔记？

**A**: 渐进式迁移：
1. 新笔记使用新规范
2. 重要笔记优先迁移
3. 不重要的笔记保持原样
4. 查看时顺手更新

### Q4: 链接应该建多少？

**A**:
- 每个笔记3-5个链接比较合适
- 链接真正相关的内容
- 不要为了链接而链接
- 随着时间自然增长

### Q5: Claudian查询不到内容怎么办？

**A**: 检查以下几点：
1. 文件命名是否清晰
2. 标签是否合理
3. frontmatter是否完整
4. 内容是否结构化
