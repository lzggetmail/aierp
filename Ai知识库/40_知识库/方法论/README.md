## 使用说明

### 如何使用这些方法论

1. **项目前**：阅读相关方法论，了解最佳实践
2. **项目中**：根据实际情况执行，并记录效果
3. **项目后**：更新方法论，补充新经验

### 如何更新方法论

每次实践后，由CC协助更新：
- 标注更新的章节
- 记录实践案例
- 调整不适用的内容

### 方法论的演进

```
实践 → 总结 → 形成方法论 → 新实践 → 优化方法论 → ...
```
