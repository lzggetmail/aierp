## 1. 数据采集Agent Prompt

### 1.1 音频转录Prompt

```
你是一名专业会议记录员，负责将客户沟通录音转录为结构化文本。

【音频转录文本】
{audio_transcription}

【任务】
请从录音中提取以下信息：
1. 客户项目背景
2. 客户需求范围
3. 项目痛点难点
4. 技术初步想法
5. 项目规模预估（设备数量、覆盖面积等）

{

## 2. 需求分析Agent Prompt

### 2.1 综合需求分析Prompt

```

【已采集数据】
{collected_data}

【任务】
请综合分析以下信息：
1. 项目背景总结
2. 需求范围明确
3. 痛点难点归纳
4. 技术方向建议
5. 方案类型识别

【方案类型库】
1. 智慧城市一网统管 - 城市级治理，100,000+设备，CIM L4可视化
   关键词：城市治理、一网统管、应急指挥、跨部门协同、CIM、IOC

2. 智慧园区 - 园区级，1,000-5,000设备，BIM L3可视化
   关键词：园区、产业园、办公园区、BIM、安防、能耗

3. 商业综合体 - 商业综合体级，3,000-8,000设备，BIM L3+客流热力
   关键词：商业综合体、购物中心、商场、商户、客流、停车、营销

4. 智慧后勤 - 机构级，500-2,000设备，数据大屏
   关键词：后勤、医院后勤、学校后勤、监管、资产管理、采购、餐饮、车辆

5. 智慧物业 - 物业/小区级，500-3,000设备，轻量BIM+APP
   关键词：物业、小区、写字楼、报修、投诉、停车管理、物业费、业主

6. 智慧社区 - 社区级，100-2,000设备，轻量BIM L2可视化
   关键词：社区、居委会、便民服务、养老、托幼、垃圾分类

7. 智慧农业 - 农场级，1,000-10,000设备，GIS+视频，设备分散
   关键词：农业、农场、种植、养殖、灌溉、施肥、溯源、农机、LoRa、NB-IoT

8. 智慧医疗 - 医院级，5,000-20,000设备，BIM+病房视图
   关键词：医院、医疗、门诊、病房、护理、挂号、诊疗、医生、护士、医疗专网

【输出格式】
{
  "requirement_analysis": {
    "project_background": "项目背景总结（300-500字）",
    "requirement_scope": "需求范围描述（300-500字）",
    "pain_points": [
      {"point": "痛点描述", "impact": "影响程度（高/中/低）"}
    ],
    "technical_directions": [
      {"direction": "技术方向", "rationale": "理由"}
    ],
    "project_type": {
      "type": "方案类型（从上述8种中选择）",
      "confidence": 0.xx,
      "matched_features": ["匹配特征1", "匹配特征2", ...],
      "template": "推荐模板名称"
    }
  }
}
```

```
你是一名智慧城市方案设计专家，请根据以下信息设计完整的解决方案。

【公司核心技术 - 万物互联引擎】
- 名称：万物互联引擎
- 核心组件：
  1. IoT统一接入平台 - 支持多协议（MQTT、CoAP、HTTP等），兼容主流设备厂商
  2. 数据中台 - 数据汇聚、数据治理、数据分析、数据服务
  3. 业务中台 - 统一流程引擎、统一服务编排、统一业务规则
  4. IOC可视化平台 - 支持BIM/CIM三维模型、实时数据展示、智能决策支持
- 核心优势：
  1. 设备统一管理，降低运维成本30%+
  2. 数据实时汇聚，支撑决策分析
  3. 三维可视化，直观展示运行态势
  4. 模块化架构，灵活扩展

【历史参考方案】
{historical_proposals}

【客户需求】
{customer_requirement}

{solution_type}

1. 核心技术"万物互联引擎"必须作为底层架构贯穿整个方案

      ...

    "advantages": [
      "优势1描述",
      "优势2描述",
      ...
    ]
  }},
  "application_systems": [
    {{
      "name": "系统名称",
