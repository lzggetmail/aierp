# AI 工具协同

> Codex / Claude Code / OpenClaw 怎么分工配合

---

## 📋 完整工作流

### 第一步：收集信息（OpenClaw Skill）
```
你浏览小红书/B站/公众号 → 看到好内容
          ↓
用 Agent Reach / X Read → 抓取全文
          ↓
自动存到 Obsidian 的 00_收件箱/
```

### 第二步：整理分类（Codex/Claude Code）
```
AI 读取 00_收件箱/ 的内容
          ↓
根据 PARA 方法自动分类：
- 项目相关 → 20_项目/
- 学习相关 → 10_日记/学习/
- 研究相关 → 30_研究/
          ↓
自动建立双向链接
```

### 第三步：人工消化（必须）
```
你阅读原文 → 理解内容 → 写自己的笔记
          ↓
补充 AI 遗漏的洞察
          ↓
添加个人思考
```

---

## 🔄 三者关系

| 工具 | 角色 | 在工作流中的位置 |
|---|---|---|
| **OpenClaw Skill** | 信息收集 | 第一步：抓取内容 |
| **Codex/Claude Code** | 自动整理 | 第二步：分类整理 |
| **人工** | 深度消化 | 第三步：理解吸收 |

---

## 💡 关键理解

**OpenClaw Skill 和 Codex 是串联关系，不是并列关系！**

```
OpenClaw Skill（收集） → Codex（整理） → 人工（消化）
```

**不是**：
```
OpenClaw Skill 或 Codex（二选一） ❌
```

---

## 🛠️ 工具分工

### OpenClaw Skill
- **强项**：联网搜索、跨平台抓取
- **弱项**：不能深度分析、不能自动整理
- **定位**：信息入口

### Codex / Claude Code
- **强项**：深度分析、自动整理、写代码
- **弱项**：不能联网抓取（需要 OpenClaw 配合）
- **定位**：智能处理器

### 人工
- **强项**：理解、判断、创造
- **弱项**：速度慢、容易累
- **定位**：最终决策者

| **抓取小红书内容** | OpenClaw Skill（Agent Reach） |
