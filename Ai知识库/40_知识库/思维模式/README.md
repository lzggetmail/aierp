## 使用说明

### 这些思维模式如何使用？

1. **学习阶段**：阅读理解，掌握核心洞察
2. **应用阶段**：在实际工作中应用这些思维
3. **优化阶段**：根据实践反馈，优化思维模式
4. **传承阶段**：教给团队成员，形成集体智慧

### 如何新增思维模式？

当你从某个地方（书籍、电影、交流、实践）学到有价值的思维时：
1. 用CC整理成文
2. 提炼核心洞察
3. 给出应用场景
4. 保存到本目录
5. 更新本索引
