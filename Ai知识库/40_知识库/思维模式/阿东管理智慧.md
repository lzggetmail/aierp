## 人物画像

### 阿东的能力模型

**背景**：

## 四大核心思维模型

### 模型1：不信"赢在起跑线" —— 赛马模型

#### 现象
大部分全程领先的马，最后冲刺被反超。

#### 本质
- 前期用力过猛 → 后程无力
- 前期战术单一 → 关键时刻被超越
- 三鼎公司的经历也印证了这一点

#### 创业迁移
> **早期风风火火的对手，不一定笑到最后。创业是长跑，节奏感和冲刺能力比起步速度更重要。过早透支（资金、团队精力、客户期待）反而是隐患。**

#### 教育维度
过早给小孩压力 = 透支兴趣和精力，后期可能"悬崩"。

---

### 模型2：语言即治理 —— Class vs Level

#### 现象
马会明明是分等级，却用"Class（班级）"而非"Level（等级）"。

#### 本质
- "Level"暗示高下之分 → 打击弱者信心
- "Class"暗示分组而非分级 → 模糊歧视感，维护所有参与者积极性

#### 核心洞察
> **制度的设计不只是逻辑正确，还要考虑人的心理感受。用词的微妙差异，决定了参与者是积极投入还是被动消极。**

#### 创业迁移

在团队管理、客户沟通中，如何用"模糊等级"的方式激励所有人？

- ❌ 不说"A级客户/B级客户"
- ✅ 而说"不同服务方案"

- ❌ 不说"核心团队/边缘团队"
- ✅ 而说"不同业务小组"

---

### 模型3：制造公平竞争的悬念 —— 负重平衡机制

#### 现象
同一班次内，好马加负重，让水平拉平。

#### 设计逻辑
```
好马 → 加负重 → 速度降下来
差马 → 不加负重 → 速度提上去
结果 → 所有马在冲刺阶段激烈竞争 → 充满悬念
```

#### 马会升降班机制
- 升班：奖金更高
- 降班：奖金分配比例降低
- 马匹进出赛前后都要称重/复磅，防止造假
- 鼓励机制：马会主动问马主"想不想升班"，用奖金吸引力驱动

#### 经典案例
一匹8岁老马，买进时约300万，总奖金累计超过1.2亿，世界排名第二。
**证明好的运营机制能激发所有参与者的积极性。**

#### 创业迁移
> **一个健康的竞争环境，不是让强者永远赢，而是通过机制设计让竞争始终有悬念、有看点。这对平台型业务（如AI创业平台）有启发——如何设计规则，让各方参与者都觉得有机会，都能保持积极性。**

---

### 模型4：时间换空间 —— 解决1.2亿资金缺口的管理杰作 ⭐

这是全篇**最有价值的案例**。

#### 背景
- 前人负责从化机房迁移项目，花了3年烂尾
- 资金缺口1.2亿
- 上级把项目重新交回给阿东

#### 阿东的策略链

```
第1步：敢于接手（奥巴马式思维——已经烂了，做不好不比现在更差，做好了就是英雄）
  ↓
第2步：方案不改（保持原方案 = 保持性能保证，推翻重来成本更高）
  ↓
第3步：拉财务上船（"我也背锅，你也背锅"——把利益绑定，从对立变成同盟）
  ↓
第4步：时间换空间（把未来3年预算平摊到当前，化解单次投入的敏感度）
  ↓
第5步：财务审核机制升级（给上级一个"改进"的交代，而不是"填坑"）
```

#### 底层思维模型对比

| 维度 | 阿东的做法 | 普通人的做法 |
|------|-----------|-------------|
| 面对烂摊子 | 敢接（已经最差了，只会更好） | 回避（怕背锅） |
| 面对资金缺口 | 不打新报告（不重复前人错误） | 重新报预算 |
| 面对利益相关方 | 绑定对方（"你也有责任"） | 单独扛 |
| 面对成本 | 时间维度展开（3年平摊） | 当前维度硬扛 |
| 面对上级 | 给"改进方案"而非"填坑方案" | 说"之前的错了" |
| 面对原方案 | 保持不改（保证性能） | 换便宜方案妥协 |

#### 核心洞察

> **当前的问题可以用未来的时间和资源进行交换。真正有能力的人，不是硬解决问题，而是转换问题的维度，让问题在另一个维度上变得可解。**

> **所有事情都是成本的考量，成本无非就是金钱和时间。如何让别人觉得"成本没花出去"，用别的方法降低对成本的敏感度，这个事情的成功就有很大的价值。**

## 视觉运营体系 —— 三位一体的服务设计

阿东讲的不是零散的技巧，而是香港马会一套**系统性的用户引导机制**。

### 1. 表格数据展示 —— 让复杂变直观

- 每场赛事前制作专门小册子，包含：
  - 马匹历史成绩
  - 骑手胜出率
  - 升班/降班记录
  - 负重信息
- 动态表格轮播展示赔率变化
- 用**表格结构**把海量信息组织成可快速扫读的格式

> **核心：不是给用户数据，而是给用户结构化的判断依据。**

### 2. 服务细节 —— 无处不在的参考信息

- 屏幕、报纸、小册子，**多渠道同步推送**赛事数据
- 每次比赛前都重新确认更新小册子，不是复用旧的
- 投注者需要的一切决策信息，运营方都**主动送到位**

> **核心：不是等用户来找信息，而是信息追着用户走。降低参与门槛，让每个人都能"懂马"。**

### 3. 颜色提醒 —— 培养用户的视觉习惯

- 不同颜色对应不同含义（赔率高低、升班降班、胜负区间）
- 单格颜色 vs 整行背景色，表达不同层级的信息
- 动态赔率变化用颜色突出，一眼看到趋势

> **核心：颜色不是装饰，是认知快捷方式。香港人从小接触这类视觉系统，已经形成本能反应。**

#### 香港人颜色标识习惯的由来
- 香港人从小接触赛马、博彩的数据表格
- 企业管理者日常用多色彩笔在进度表、排期表上做标识
- 整行背景色 vs 单格颜色 vs 前面数字颜色，各有不同表达含义
- 这在大陆很少见，因为从小教育体系不同

### 三者合力的效果

```
表格（结构化）+ 服务细节（触手可及）+ 颜色（视觉引导）
          ↓
   用户不需要专业背景，也能快速做出判断
          ↓
   降低参与门槛 → 提高参与意愿 → 形成使用习惯
```

这其实就是一种**"保姆式运营"**——不是要求用户变聪明，而是通过服务设计让普通人也能像专家一样参与。

## 对AI创业的直接启发

| 阿东的智慧 | 对创业的启示 |
|-----------|------------|
| **不信赢在起跑线** | 别急于一时的风头，保持节奏，长期主义 |
| **Class而非Level** | 产品/客户分层时，用"包容"而非"歧视"的语言和设计 |
| **负重平衡机制** | 平台设计中，让所有参与者觉得公平、有机会 |
| **时间换空间** | 当前困难可以用未来资源交换，不要只在当前维度死磕 |
| **利益绑定** | 把相关方变成同盟而非对手 |
| **成本敏感度管理** | 不是降低成本，而是**降低对方对成本的感知** |
| **表格结构化数据** | AI分析结果不要一堆文字，要用表格/卡片结构化呈现 |
| **信息主动触达** | 不要让客户去找数据，AI要主动把关键信息送到他眼前 |
| **颜色视觉引导** | 产品界面用颜色区分优先级、状态、风险等级，降低客户认知成本 |
| **每次更新都重新确认** | 给客户的报告/方案，每次都要更新到最新状态，体现专业和用心 |
