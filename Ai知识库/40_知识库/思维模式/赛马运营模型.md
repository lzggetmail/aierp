# 赛马运营模型

> **来源**：香港马会观察
> **观察者**：李志刚
> **整理日期**：2026-04-23

---

## 核心洞察

### 不信"赢在起跑线" ⭐

**现象**：大部分全程领先的马，最后冲刺被反超。

**本质**：
- 前期用力过猛 → 后程无力
- 前期战术单一 → 关键时刻被超越
- 三鼎公司的经历也印证了这一点

**创业迁移**：
> **早期风风火火的对手，不一定笑到最后。创业是长跑，节奏感和冲刺能力比起步速度更重要。过早透支（资金、团队精力、客户期待）反而是隐患。**

**教育维度**：
过早给小孩压力 = 透支兴趣和精力，后期可能"悬崩"。

## 负重平衡机制

### 现象
同一班次内，好马加负重，让水平拉平。

### 设计逻辑

```
好马 → 加负重 → 速度降下来
差马 → 不加负重 → 速度提上去
结果 → 所有马在冲刺阶段激烈竞争 → 充满悬念
```

### 马会升降班机制

- **升班**：奖金更高
- **降班**：奖金分配比例降低
- **防造假**：马匹进出赛前后都要称重/复磅
- **激励**：马会主动问马主"想不想升班"，用奖金吸引力驱动

### 经典案例
一匹8岁老马，买进时约300万，总奖金累计超过1.2亿，世界排名第二。
**证明好的运营机制能激发所有参与者的积极性。**

### 创业迁移

> **一个健康的竞争环境，不是让强者永远赢，而是通过机制设计让竞争始终有悬念、有看点。这对平台型业务（如AI创业平台）有启发——如何设计规则，让各方参与者都觉得有机会，都能保持积极性。**

## Class vs Level —— 语言即治理

### 现象
马会明明是分等级，却用"Class（班级）"而非"Level（等级）"。

### 本质
- "Level"暗示高下之分 → 打击弱者信心
- "Class"暗示分组而非分级 → 模糊歧视感，维护所有参与者积极性

### 核心洞察

> **制度的设计不只是逻辑正确，还要考虑人的心理感受。用词的微妙差异，决定了参与者是积极投入还是被动消极。**

### 创业迁移

在团队管理、客户沟通中，如何用"模糊等级"的方式激励所有人？

**客户分类**：
- ❌ "A级客户/B级客户"（歧视感）
- ✅ "不同服务方案"（包容感）

**团队分组**：
- ❌ "核心团队/边缘团队"（歧视感）
- ✅ "不同业务小组"（包容感）

**产品定价**：
- ❌ "高级版/基础版"（歧视感）
- ✅ "专业版/标准版"（包容感）

## 视觉运营体系

### 1. 表格数据展示 —— 让复杂变直观

**做法**：
- 每场赛事前制作专门小册子
- 包含：马匹历史成绩、骑手胜出率、升班/降班记录、负重信息
- 动态表格轮播展示赔率变化
- 用**表格结构**把海量信息组织成可快速扫读的格式

**核心**：
> **不是给用户数据，而是给用户结构化的判断依据。**

### 2. 服务细节 —— 无处不在的参考信息

**做法**：
- 屏幕、报纸、小册子，**多渠道同步推送**赛事数据
- 每次比赛前都重新确认更新小册子，不是复用旧的
- 投注者需要的一切决策信息，运营方都**主动送到位**

**核心**：
> **不是等用户来找信息，而是信息追着用户走。降低参与门槛，让每个人都能"懂马"。**

### 3. 颜色提醒 —— 培养用户的视觉习惯

**做法**：
- 不同颜色对应不同含义（赔率高低、升班降班、胜负区间）
- 单格颜色 vs 整行背景色，表达不同层级的信息
- 动态赔率变化用颜色突出，一眼看到趋势

**核心**：
> **颜色不是装饰，是认知快捷方式。香港人从小接触这类视觉系统，已经形成本能反应。**

### 三者合力的效果

```
表格（结构化）+ 服务细节（触手可及）+ 颜色（视觉引导）
          ↓
   用户不需要专业背景，也能快速做出判断
          ↓
   降低参与门槛 → 提高参与意愿 → 形成使用习惯
```

## 香港人颜色标识习惯

### 由来
- 香港人从小接触赛马、博彩的数据表格
- 企业管理者日常用多色彩笔在进度表、排期表上做标识
- 整行背景色 vs 单格颜色 vs 前面数字颜色，各有不同表达含义

### 与大陆的差异
- **香港**：从小教育培养了对颜色标识的本能反应
- **大陆**：很少见这类视觉系统，教育体系不同

### 延伸：博彩业的视觉设计

**澳门百家乐**：
- 大小区域的图形设计
- 颜色区分
- 赔率展示

**核心逻辑**：
- 押注区域的大小设计
- 视觉感受
- 图案、数字大小、颜色等做视觉区分

**这套视觉体系在博彩业运用极其广泛和成熟。**

## 赛马运营数据

### 基本运营数据
- 每天十几个亿押注金额（有赛事日）
- 一天十几场赛事
- 全世界可远程下注

### 投注方式多样
- 头马（押一匹马跑第一）
- 前两名精确押注
- 前三名押注（不分先后）
- 连环押（连续多匹马）
- 各种组合投注

### 赔率规律
- 赔率实时动态调整，根据投注情况变化
- 大热门（低赔率）的马往往不会稳赢
- 最不被看好的（高赔率）胜出概率极低
- 往往是中间地带的马充满悬念，赛事的魅力所在

### 核心运营逻辑

> **马会通过运营手段调控各场次奖金高低，差马赛局奖金200多万，顶级可达2000多万。投注金额固定（每注费用相同），与马的好坏无关，只看号码。真正的好坏通过赔率动态调节。**

## 对AI创业的启发

| 赛马运营智慧 | 对AI创业的启示 |
|-------------|---------------|
| **不信赢在起跑线** | 别急于一时的风头，保持节奏，长期主义 |
| **负重平衡机制** | 平台设计中，让所有参与者觉得公平、有机会 |
| **Class而非Level** | 产品/客户分层时，用"包容"而非"歧视"的语言 |
| **表格结构化** | AI分析结果要用表格/卡片结构化呈现 |
| **信息主动触达** | 不要让客户去找数据，AI要主动把信息送到眼前 |
| **颜色视觉引导** | 产品界面用颜色区分优先级、状态、风险等级 |
