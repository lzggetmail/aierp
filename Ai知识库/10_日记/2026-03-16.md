3. **配置是关键** - 很多功能需要配置环境变量
4. **心跳 vs 定时** - 心跳是被动检查，定时是主动推送
5. **Markdown 只是"衣服"** - AI 理解的是语义，不是语法
6. **Git 上传遇到的问题**：
   - `.env` 文件不能上传（敏感信息）
   - `tmpclaude-*` 是 CC 临时文件，要排除
   - Windows 的 `nul` 是系统保留名，加入 `.gitignore` 即可
   - 推送前必须先 `git commit`

## Git 上传踩坑记录（续）

### 问题6：GitHub 单文件限制

**错误信息**：
```
File SmartCityPPT2.5.1.zip is 277.71 MB; this exceeds GitHub's file size limit of 100.00 MB
```

**解决方法**：
```powershell
# 排除大文件
echo "SmartCityPPT2.5.1.zip" >> .gitignore
git rm --cached SmartCityPPT2.5.1.zip
git add .
git commit -m "移除大文件"
git push -u origin main
```

### Git 上传完整流程（Windows）

```powershell
# 1. 配置用户（首次）
git config --global user.name "李志刚"
git config --global user.email "你的邮箱"

# 2. 创建 .gitignore
echo ".env
tmpclaude-*
nul
*.zip
__pycache__/
*.pyc" > .gitignore

# 3. 添加文件
git add .

# 4. 提交
git commit -m "项目初始化"

# 5. 推送
git push -u origin main
```

### GitHub 限制

| 限制 | 说明 |
|------|------|
| 单文件 | 最大 100 MB |
| 仓库总大小 | 建议 < 1 GB |
| 大文件方案 | Git LFS |
