# 小天：你为什么觉得 OpenClaw 没用？

> 来源：小天视频
> 整理时间：2026-03-17

---

## 核心观点

### 1. 自媒体被算法支配

**真相**：
- 自媒体/博主都是被算法支配的
- 必须用"看衰"标题来吸引流量
- 内容本身可能很有价值，但标题有情绪

**判断标准**：
> 能不能从一个视频里获得**立刻行动起来的动力和方向**？如果能让你动起来，就是优秀的信息。

---

## 2. 为什么看衰 OpenClaw 的观点能引起共鸣？

小天认为有三个原因：

| 原因 | 说明 |
|------|------|
| **1. 看不到能力边界** | 大部分人不知道 OpenClaw 能干什么，也忽略了它正在飞速发展 |
| **2. 误解核心循环** | 把 OpenClaw 当成"超级机器人"，而不是"生存建造类游戏" |
| **3. 选错工具** | 用 OpenClaw 做复杂编码任务，效率很低，应该用 Claude Code |

---

## 3. OpenClaw 的正确定位

**不是**：超级机器人，直接给你赚钱

**而是**：生存建造类游戏

| 概念 | 说明 |
|------|------|
| **养成 Agent** | 训练你的 AI 助手 |
| **建设基地** | 构建自己的商业闭环基础设施 |

---

## 4. 正确的工具选择

| 任务 | 工具 |
|------|------|
| **开发 Skills / 复杂编码** | Claude Code |
| **运行 Skills / 日常运营** | OpenClaw |

**关键认知**：
> 用 Claude Code 做 Skills，用 OpenClaw 来运行它

---

## 5. 跟上 OpenClaw 发展的技巧

### 技巧1：让龙虾记住你的代码库

```bash
gh login  # 登录 GitHub
gh ...    # 龙虾可以根据代码变动给你总结更新
```

### 技巧2：搜索最近合并的 PR

- 让龙虾通过 GH 命令搜索过去 24-48 小时合并的 PR
- 根据简报筛选感兴趣的功能变化
- 做深入问答

### 技巧3：关注关键词

- 长期关注的问题 → 提炼关键词
- 让龙虾在 Reddit/GitHub 帮你发现相关更新
- 定期搜索关注的代码库

**例子**：
- 关注 Mac 推理速度 → 关键词：fix cache、KV cache、MLX
- 让龙虾在 Reddit 发现 MLX 加速神器

### 技巧4：浏览器功能

**痛点**：Claude Code 操作浏览器经常被反扒机制 block

**OpenClaw 优势**：
- 可以操作浏览器
- 支持远程调试
- 可以看你正在看的网页

**用法**：
- 让 OpenClaw 扫 Peter 的推，获取关键更新
- 在 Reddit/X 上搜索长期关注的关键词
- 找线索、找代码、给答案

---

## 6. OpenClaw 浏览器功能的演进

| 版本 | 变化 |
|------|------|
| **3月3日前** | 推荐使用浏览器插件模式 |
| **3.11版本** | 改为默认使用隔离模式（开新浏览器） |
| **3.13版本** | 明确不推荐使用插件模式 |
| **3.14版本** | Chrome 146 发布后，浏览器功能越来越好用 |

**结论**：
> OpenClaw 正在变得越来越强大、越来越好用
