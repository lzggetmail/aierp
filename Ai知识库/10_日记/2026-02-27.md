### 核心概念
- **Agent**: 智能代理 = LLM + 工具 + 记忆
- **Tools**: Agent 可调用的函数
- **System Prompt**: 定义 Agent 行为
- **Runtime Context**: 工具运行时上下文
- **Checkpointer**: 保存对话状态
- **Thread ID**: 标识对话

### 关键代码模式

#### 创建工具
```python
from langchain.tools import tool

@tool
def my_function(param: str) -> str:
    """清晰的描述很重要"""
    return "result"
```

#### 创建 Agent
```python
agent = create_agent(
    model=model,
    tools=[...],
    system_prompt="...",
    checkpointer=checkpointer
)
```

#### 使用记忆
```python
config = {"configurable": {"thread_id": "conversation-1"}}
agent.invoke(messages, config=config)
```
