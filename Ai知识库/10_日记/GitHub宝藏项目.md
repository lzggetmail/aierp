### 创意验证/竞品搜索

| 项目 | 说明 | 状态 |
|------|------|------|
| [Mnemox.ai - Idea Reality Check](https://mnemox.ai/check/) | **淘金第一站**：输入想法 → 自动搜索 GitHub 等平台 → 直接给出最高星项目链接 → 一键克隆使用 | ✅ 常用工具 |

**核心功能**：
- **输入想法** → 描述你想做什么
- **多源搜索** → GitHub、Hacker News、npm、PyPI、Product Hunt 同时扫描
- **直接给链接** → 最高星项目的仓库链接，一键访问
- **直接克隆** → 不需要封装成 Skill，直接拿源码用
- **市场评分** → 0-100 分，判断市场是否值得进入

**与 ClawHub 的区别**：
| ClawHub | Mnemox.ai |
|---------|-----------|
| 找封装好的 Skills | 找任意开源项目 |
| 安装后才能用 | 直接克隆源码 |
| 功能已固定 | 可以自己改、组合 |

**使用流程**：
```
有想法 → Mnemox 搜索 → 找到高星项目 → 克隆 → 用起来/改造成自己的
```
