# 李一舟：龙虾带来的挑战，如何做一人公司

> 来源：李一舟分享
> 整理时间：2026-03-17

---

## 核心观点

### 1. OpenClaw 改变了一切

**李一舟的亲身体验：**
- 80% 的工作原来不可外包
- 这一个月以来，专用工作笔记本不再打开
- Claude Code 打开率降低 50%
- 主力工具：Mac mini 桌面版 OpenClaw + 手机 Telegram

**原因：OpenClaw 太方便了**

### 2. 实际应用场景

**场景一：日程管理**
- 接孩子这种琐事，口头发命令给 AI 助理
- AI 自动判断时间冲突、提醒
- 随时随地丢任务，AI 帮你处理

**场景二：投资研究**
- 专门的"投资思考"topic
- 丢链接（研报、公众号、知乎、小红书）
- AI 自动穿透、读完、归档、形成投资框架

**场景三：多 Agent 协作**
- 投资助理 + 公司管理 Agent 搭配
- 让他们互相讨论、反驳、沟通
- 达到要求才汇报
- 就像跨部门协作，拉个群让他们干活

### 3. AI 时代的三个核心能力

| 能力 | 说明 |
|------|------|
| **折腾能力** | 从0到1的过程不教，要自己折腾 |
| **好奇心** | GitHub 上淘金，找璞玉，组合成生产力工具 |
| **费曼学习法** | 听→做→表达，找志同道合的人一起迭代 |

### 4. 两类人会"很麻烦"

| 类型 | 原因 |
|------|------|
| **职场新人** | 公司不再培训，直接用 AI 员工 |
| **迷茫的中年人** | 初级/中级白领工作被压缩，十年经验瞬间被 AI 掌握 |

### 5. 李想的观点（李一舟翻译）

> **老油条/老油鸟 + AI 能力 = YYDS**

**关键洞察：**
- 没有领域知识和资源的人 + AI = 更厉害的小白
- 本身是老板/专家/大牛 + AI = 恐怖的强大

**李一舟的感受：**
> 流量资源 + OpenClaw + AI = 能力强了不止十倍

## 对志刚的启发

### 优势确认

志刚正是"老油鸟"类型：
- IT 背景 + ERP 经验 + 智慧城市
- 企业管理经验
- 人脉资源
- 复合型能力（技术×传统×沟通）

**加上 AI = 巨大优势**

### 可以借鉴的做法

1. **多 Agent 协作**
   - 投资助理 + 公司管理 Agent
   - 让 Agent 互相讨论、反驳
   - 达到要求才汇报

2. **Topic 分类管理**
   - 投资思考
   - 项目管理
   - 学习笔记
   - 客户关系

3. **随时随地丢任务**
   - 手机 Telegram 随时发命令
   - AI 在后台处理
   - 结果自动推送

### 核心认知

> "我的算力依然用不完，因为我没有那么多的足够好的项目去用去开发"

**这和志刚的情况一致**：有 AI 能力，但需要找到好的项目去应用

---

## 行动建议

1. **继续折腾 OpenClaw**
   - 不追求完美配置
   - 边用边优化

2. **建立 Topic 分类**
   - 投资研究
   - 项目管理
   - 客户关系
   - 学习成长

3. **尝试多 Agent 协作**
   - 设计不同角色的 Agent
   - 让他们互相配合

4. **找到"足够好的项目"**
   - 把 AI 能力应用到实际业务
   - 用项目驱动学习

---

*李一舟的结论：从超级个体变成 AI 一人公司，再成为龙虾的无人公司*
