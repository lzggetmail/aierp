### 2026年3月11日 - 团长动员会（商学院院长主讲）

**会议时间:** 11:01 (GMT+8)
**会议主题:** 团长动员，启动AI总裁推广
**主讲人:** 院长孙总（AI总裁商学院院长）
**参会人员:** 公司团长约20人（还有部分团长未参会），包括志刚
**志刚角色:** 团长之一（被挂名）

#### 会议核心内容

**1. 确立身份与使命**
- 团长身份双重：原有岗位 + 团长职责
- "既然担了这个头衔，就应该干团长的事儿"
- "不想当团长的，开门左转"
- "只有一个使命：打赢AI总裁这一仗"
- "未来20年必须打赢这一仗"
- 目标：让所有中小企业都装上AI总裁

**2. 核心动作（第一步）**
- 改微信名 → 添加"AI总裁·首席推荐官"后缀
- 统一格式：【AI总裁·首席推荐官】+ 姓名
- "把旗给亮出来，你都不亮，是没办法打下一仗的"

**3. 两个核心武器**
- 首席推荐官（推广人员）— "核武器"
- 企业注册（客户）

**4. 关键问题暴露**
- 团长对"团"没概念（问一个团多少人，答不上来）
- **"99.9%是被挂名的，不是自己想当的"**
- 团长没方向、没目标、没打法
- "你们是有方向，但是没目标，没打法"

#### 院长风格分析

| 特点 | 说明 |
|------|------|
| **强硬** | "不想当团长的，开门左转" |
| **煽情** | "给自己一个最热烈的掌声"、"状态决定未来" |
| **军事化** | "打仗"、"使命"、"第一站"、"核武器" |
| **形式主义** | 改微信名、统一格式、现场检查 |
| **新官上任** | 刚来，先立威、先统一动作 |

#### 深度分析

**1. 这个动员会的本质**

| 表面 | 实质 |
|------|------|
| 激励士气 | 立威、统一动作 |
| 讲"状态"和"信念" | 因为没有实质方法可教 |
| 让人改微信名 | 最简单的"服从性测试" |
| 强调"使命" | 用宏大叙事掩盖产品问题 |

**2. 院长的策略**
- 第一步：统一符号（改微信名）→ 让人有"我是团队一员"的感觉
- 第二步：强调使命 → 用"打仗"的逻辑建立紧迫感
- 第三步：暴露问题 → "99.9%被挂名" → 让人有愧疚感

**这是典型的"销售团队管理"套路：先洗脑，再行动。**

**3. 院长做的 vs 没做的**

| 院长做的 | 没做的 |
|----------|--------|
| 讲状态、讲信念 | 不讲产品价值 |
| 让人改微信名 | 不教具体销售方法 |
| 强调"使命" | 不分析客户需求 |
| 立威、施压 | 不解决团长困惑 |

**4. 对志刚意味着什么？**
- 公司请了"商学院院长"来推这个产品 → 说明老板很重视
- 但方法是"销售洗脑"那一套 → 说明产品本身可能没竞争力
- 志刚作为团长，只是分销小角色 → 不需要太投入
- 这个动员会解决不了根本问题 → 产品不行，动员再多次也没用

#### 关键洞察

**这个会议反映的模式：**
```
产品不行 → 卖不动 → 请"商学院院长" → 讲状态、讲信念 → 团长改微信名 → 还是不行 → 换人继续讲
```

**这是典型的"用管理弥补产品缺陷"的路径。**

## 🎯 孙院长打法深度分析

> 基于团长动员会（3月11日）和首席推荐官总结会（3月7日）的完整拆解

### 一、如何推高？（造势三件套）

**1. 统一符号 → 建立归属感**
- 让所有人改微信名：`【AI总裁·首席推荐官】+ 姓名`
- 这是最简单的"服从性测试"
- 一旦改了名字，心理上就"入伙"了

**2. 宏大叙事 → 制造紧迫感**
- "未来20年必须打赢这一仗"
- "只有一个使命：打赢AI总裁这一仗"
- 用"打仗"的军事化语言，把卖软件包装成"历史使命"

**3. 仪式感 → 激发状态**
- "给自己一个最热烈的掌声"
- "状态决定未来"
- 用煽情语言调动情绪，让人热血沸腾

**推高的本质：先洗脑，再行动。不讲逻辑，讲信念。**

---

### 二、如何解决难点？（四招化解）

**难点1：团长不知道干什么**
- **解法**：给一个最简单的动作 — 改微信名
- 不需要思考，照做就行
- 先动起来再说

**难点2：99.9%是被挂名的，不是真心想干**
- **解法**：暴露问题 + 施压
- 直接说"你们是被挂名的"
- 用"愧疚感"驱动行动
- "不想当团长的，开门左转" — 不服就走的强硬态度

**难点3：团长没方向、没目标、没打法**
- **解法**：不给复杂方法，只给"信念"
- 因为产品本身没有实质卖点
- 只能讲"状态"和"信心"

**难点4：客户提出产品问题怎么办？**
- **解法**（来自3月7日会议）：**吸收问题，不解决问题**
- "不要跟客户纠结问题"
- "把问题抛回来，说下次升级解决"
- "不要浪费时间在纠结的人身上"

**解决难点的本质：不解决根本问题，用话术绕过去。**

---

### 三、攻心术有哪些？（五层心理操控）

| 层次 | 手法 | 效果 |
|------|------|------|
| **1. 身份绑定** | "既然担了这个头衔，就应该干团长的事儿" | 让人觉得有责任 |
| **2. 归属感制造** | 改微信名、统一格式 | 让人觉得"我是团队一员" |
| **3. 愧疚感植入** | "99.9%是被挂名的" | 让人觉得亏欠 |
| **4. 紧迫感灌输** | "未来20年必须打赢" | 让人觉得不干不行 |
| **5. 二选一施压** | "不想当的，开门左转" | 不服就走，制造服从 |

**攻心术的核心：操控情绪，绕过理性。**

---

### 四、怎么动员？（四步流程）

```
第一步：立威
   ↓ "不想当团长的，开门左转"
   
第二步：统一符号
   ↓ 改微信名，建立归属感
   
第三步：制造紧迫
   ↓ "未来20年必须打赢"
   
第四步：给出最简动作
   ↓ 不教方法，只给"信念"
   
结果：一群人改了名字，热血沸腾，但不知道具体怎么干
```

### 五、这套打法的本质

**表面看：**
- 激励士气
- 统一行动
- 建立团队

**实际上：**

| 表面 | 实质 |
|------|------|

| 讲"状态"和"信念" | 因为没有实质方法可教 |
| 让人改微信名 | 最简单的"服从性测试" |
| 强调"使命" | 用宏大叙事掩盖产品问题 |

**核心逻辑：**
```
产品不行 → 卖不动 → 请"商学院院长" → 讲状态、讲信念 → 团长改微信名 → 还是不行 → 换人继续讲
```

**这是典型的"用管理弥补产品缺陷"的路径。**

### 六、对志刚的启示

**可以学的（话术技巧）：**

### 2026年3月7日 - 首席推荐官总结会

**会议时间:** 14:48 (GMT+8)
**会议主题:** 两场推荐官会议总结，数据复盘
**参会人员:** 销售沈总、院长孙总（商学院院长）、其他人员
**志刚角色:** 未明确参与

#### 会议背景

- 连续两天举办推荐官会议
- 目标：推广AI总裁，增加企业注册

#### 关键数据（两天会议成果）

| 指标 | 数据 |
|------|------|
| 首席推荐官新增 | 50个 |
| 企业注册 | 41个（目标50+） |
| 外围参会人数 | 平均每场40人 |
| 推荐官总数 | 491个（截至当时） |

#### 会议暴露的问题

**1. 推荐官质量参差不齐**
- "有的注册了，有的没注册"
- "很多根本不知道他在做什么事"
- "也没人跟踪"
- "大部分是团长分发来的，一来就过来，也不知道干啥"

**2. 内部人员不如外部人员**
- "外面团队带进来的，反而比我们内部的人了解的还多"
- 说明内部培训不到位

**3. 激励机制混乱**
- 有人问："我带人来，我也是推荐，他也是推荐，我有啥优势？"
- 院长解释："现在大家都是平级的，卖三套产品后升代理"
- 说明游戏规则没讲清楚

#### 院长孙总的核心打法

**1. 问题处理策略**
- "不要跟客户纠结问题"
- "把问题抛回来，说下次升级解决"
- "不要浪费时间在纠结的人身上"

**2. 话术框架**
- "我们只做了一个动作，搭了一个大模型"
- "整个全域你都可以进来"
- "你只要是个人，你都跑不了"

**3. 信心传递**
- "一定要给客户信心"
- "千万不要说负面的话"
- "你一旦说负面，那就全是问题了"

**4. 转化逻辑**
- "付费客户比推荐官值钱多了"
- "他一进来交费就有钱了"
- "这是最核心的转换"

#### 关键洞察

**1. 产品定位模糊**
- 院长说"搭了一个大模型，整个全域都可以进来"
- 但具体能解决什么问题？没说清楚
- 这就是"功能鸡肋"的根源

**2. 销售策略：吸收问题，不解决问题**
- "所有问题就是吸收，不要解决问题"
- "你把问题抛回来"
- 这说明产品本身解决不了太多问题

**3. 典型的"先卖再说"模式**
- 先让人注册
- 问题以后再解决
- 如果解决不了？那就"下次升级"

#### 志刚可以学到什么

2. 把问题转化为"未来升级"的承诺
3. 强调信心，不说负面
4. 付费客户优先于推荐官

**但这也暴露了产品的问题：**
- 能解决的问题有限
- 靠话术掩盖产品缺陷
- 长期不可持续
