## 🎯 四、快速参考卡片

### 卡片 1：提示词核心要素

```
提示词 = 角色 + 任务 + 框架 + 格式 + 限制

角色：作为一位[资深顾问/技术专家/行业分析师]
任务：请[分析/评估/设计/总结]
框架：从[维度1][维度2][维度3]角度
格式：用[表格/列表/大纲]形式呈现
限制：仅基于文档，[字数/数量]限制

示例：
"作为一位资深管理咨询顾问，请从战略、组织、
流程、技术四个维度，用表格形式分析客户面临
的数字化转型挑战，每个维度列出3个关键问题。"
```

### 卡片 2：分析框架速查

```
5W2H - 问题诊断
What, Why, Who, When, Where, How, How much

SWOT - 现状评估
Strengths, Weaknesses, Opportunities, Threats

PESTLE - 环境分析
Political, Economic, Social, Technological, Legal, Environmental

金字塔 - 逻辑梳理
核心结论 → 主要论点 → 支撑论据

时间维度 - 发展分析
过去 → 现在 → 未来
```

### 卡片 3：PPT 页数参考

```
15 分钟汇报：10-15 页
30 分钟汇报：20-25 页
45 分钟汇报：30-35 页
60 分钟汇报：40-45 页

基本原则：
- 每分钟 0.5-0.8 页
- 留出 Q&A 时间
- 核心内容占 70%
- 辅助内容占 30%
```

### 卡片 4：常用修改指令

```
布局调整：
"把这一页分成两页"
"调整为上下布局"
"把图表放在中央"

内容优化：
"简化文字，每点不超过10字"
"突出显示关键数据"
"增加一个对比表格"

视觉优化：
"使用更大的字体"
"调整配色，增强对比"
"统一标题格式"
```

## 🎓 使用建议

### 如何使用这些模板？

```
1. **直接复制**：复制模板到 NotebookLM
2. **修改占位符**：替换 [ ] 中的内容
3. **补充细节**：根据项目增加细节
4. **测试优化**：测试效果并迭代优化
5. **保存版本**：保存自己的优化版本
```

### 建立自己的模板库

```
1. 使用提供的模板
2. 根据实际情况调整
3. 记录哪些提示词效果好
4. 形成个人化模板
5. 持续迭代优化
```
