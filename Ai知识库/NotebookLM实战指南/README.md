## 💡 使用技巧

### 技巧 1：建立双向链接

在笔记中使用 `[[链接]]` 建立关联：

```markdown
我正在学习提示词技巧，参考 [[03-提示词工程技巧]]
```

### 技巧 2：使用标签

添加标签方便分类：

```markdown
这是一个实用的模板 #类型/模板 #难度/入门
```

### 技巧 3：创建别名

为长标题创建别名：

```markdown
[[提示词工程|提示词]]
[[PPT制作实战|PPT]]
```

### 技巧 4：使用引用

引用其他笔记的内容：

```markdown
![[03-提示词工程技巧#核心公式]]
```
