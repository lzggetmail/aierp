## 📊 为什么资料质量至关重要？

### 资料质量决定输出质量

```
垃圾输入 → 垃圾输出（Garbage In, Garbage Out）

高质量资料 → 高质量分析 → 高质量方案
```

### NotebookLM 的特点

- ✅ **严格基于您的资料**：不会凭空创造内容
- ✅ **所有结论有来源**：可追溯到具体文档
- ✅ **资料越多越全面**：但需要精选

### 资料质量的影响

| 资料质量 | 分析深度 | 可信度 | 实用性 |
|----------|----------|--------|--------|
| ❌ 低质量 | 浅层分析 | 低 | 难以使用 |
| ✅ 高质量 | 深度洞察 | 高 | 直接可用 |

## 🎯 第一步：明确资料需求

### 分析您的项目

在寻找资料前，先回答这些问题：

```
1. 项目目标是什么？
```

## 📋 第四步：资料质量评估

### 评估维度清单

#### ✅ 权威性
```
- 来源机构是否知名？
- 作者是否有资质？
- 是否有同行评审？
- 是否被广泛引用？
```

#### ✅ 时效性
```
- 发布时间（优选 2024-2025）
- 数据是否最新？
- 是否有更新版本？
- 是否过时？
```

#### ✅ 相关性
```
- 与项目主题相关度？
- 信息深度是否足够？
- 是否能支撑论证？
- 是否有独特价值？
```

#### ✅ 可靠性
```
- 数据是否有来源？
- 方法论是否清晰？
- 结论是否有支撑？
- 是否存在明显偏见？
```

### 快速筛选技巧

#### 30 秒快速评估

```
1. 看标题和摘要 → 是否相关？
2. 看发布时间 → 是否最新？
3. 看来源机构 → 是否权威？
4. 看数据图表 → 是否专业？
5. 看引用次数 → 是否有价值？
```

#### 质量等级分类

```
⭐⭐⭐⭐⭐ 必须添加
- 顶级咨询公司最新报告
- 知名机构深度研究
- 权威期刊论文

⭐⭐⭐⭐ 推荐添加
- 行业领先企业案例
- 专业机构研究报告
- 实践性强的文章

⭐⭐⭐ 可选添加
- 行业媒体报道
- 专家观点文章
- 经验分享内容

⭐⭐ 不建议添加
- 纯广告内容
- 来源不明的信息
- 明显过时的内容
```

## 📦 第五步：添加到 NotebookLM

### 支持的来源类型

| 类型 | 说明 | 限制 |
|------|------|------|
| 📄 **上传文件** | PDF, DOC, TXT, MD | 单文件 50MB |
| 🔗 **网站链接** | 直接粘贴 URL | 自动抓取 |
| 📝 **Google Docs** | 从 Drive 选择 | 需授权 |
| 🎬 **YouTube** | 视频 URL | 自动转录 |
| 📄 **已复制文本** | 直接粘贴文本 | 5 万字 |

### 添加流程

#### 方式 1：网站链接（推荐）

```
1. 复制报告 URL
2. NotebookLM 中点击 "+ 添加来源"
3. 选择 "网站链接"
4. 粘贴 URL
5. 点击"添加"
6. 等待处理（30 秒 - 2 分钟）
```

#### 方式 2：上传文件

```
1. 下载 PDF 到本地
2. NotebookLM 中点击 "+ 添加来源"
3. 选择 "上传文件"
4. 选择文件
5. 等待上传和处理
```

#### 方式 3：Google Docs

```
1. 将内容复制到 Google Docs
2. NotebookLM 中选择 "从 Drive 选择"
3. 选择文档
4. 等待处理
```

## ⚠️ 常见问题

### Q1: 找不到高质量的免费报告？

**解决方案**：
1. 优先选择咨询公司的 Insights 页面（大量免费）
2. 使用 `filetype:pdf` 搜索报告
3. 关注机构的微信公众号
4. 参加行业活动获取资料

### Q2: 报告太多，如何筛选？

**快速筛选流程**：
```
1. 看标题和摘要（10秒）
   → 不相关？跳过

2. 看发布时间（5秒）
   → 超过 3 年？跳过

3. 看来源机构（5秒）
   → 不知名？降低优先级

4. 看目录（20秒）
   → 无实质内容？跳过

5. 看数据图表（20秒）
   → 无数据支撑？跳过
```

### Q3: 添加到 NotebookLM 后处理失败？

**原因和解决**：
- URL 需要登录 → 下载后上传文件
- 文件过大 → 分割文件
- 格式不支持 → 转换为 PDF
- 网络问题 → 稍后重试

### Q4: 如何找到最新的资料？

**技巧**：
```bash
# Google 搜索限定时间
"数字化转型趋势" after:2024

# 按时间排序
选择"工具" → "过去一年"

# 订阅更新
设置 Google 快讯
```
