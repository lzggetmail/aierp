## 🧠 什么是多维度分析？

### 核心理念

```
单一维度 → 浅层理解
多维度分析 → 深度洞察

多维度分析 = 从不同角度、层次、视角全面理解主题
```

### 为什么需要多维度分析？

```
📊 信息更全面
   ↓
🔍 洞察更深入
   ↓
💡 结论更可靠
   ↓
✅ 方案更完善
```

### NotebookLM 中的多维度分析

```
文档主题
    ↓
┌───┴───┬─────────┬─────────┐
│       │         │         │
技术维度 商业维度  用户维度  竞争维度
│       │         │         │
└───┬───┴─────────┴─────────┘
    ↓
综合洞察 → 更好的决策
```

## 🎯 常用分析框架

### 框架 1：5W2H 分析法

#### 适用场景
- 问题诊断
- 项目规划
- 需求分析

#### 分析维度

```
What（是什么）
- 问题的本质是什么？
- 涉及哪些内容？

Why（为什么）
- 为什么会出现这个问题？
- 为什么需要解决这个问题？

Who（谁）
- 谁受到影响？
- 谁是关键利益相关者？
- 谁能解决问题？

When（何时）
- 什么时候发生的？
- 什么时候需要解决？

Where（何地）
- 在什么环境下发生？
- 涉及哪些范围？

How（如何）
- 如何解决？
- 如何实施？

How much（多少）
- 需要多少资源？
- 成本和收益是多少？
```

#### NotebookLM 提示词模板

```
请用 5W2H 法分析文档中的[主题]：

## What - 问题本质
- 核心问题是什么？
- 涉及哪些具体内容？

## Why - 原因分析
- 为什么会出现？
- 根本原因是什么？

## Who - 利益相关者
- 谁受到影响？
- 谁是关键决策者？

## When - 时间维度
- 何时发生？
- 何时需要行动？

## Where - 范围界定
- 影响范围有多大？
- 在什么环境下发生？

## How - 解决方式
- 如何解决？
- 实施路径是什么？

## How Much - 资源评估
- 需要多少投入？
- 预期收益如何？

请以表格形式总结。
```

### 框架 2：SWOT 分析

#### 适用场景
- 战略规划
- 方案评估
- 竞争分析

#### 分析维度

```
Strengths（优势）
- 内部优势
- 独特能力
- 竞争优势

Weaknesses（劣势）
- 内部短板
- 能力不足
- 资源限制

Opportunities（机会）
- 外部机遇
- 市场趋势
- 政策红利

Threats（威胁）
- 外部挑战
- 竞争压力
- 风险因素
```

#### NotebookLM 提示词模板

```
请对[主题]进行 SWOT 分析：

## Strengths - 优势
请列出 5-7 项内部优势：
- 每项优势的说明
- 支撑证据
- 重要性评估

## Weaknesses - 劣势
请列出 5-7 项内部劣势：
- 每项劣势的说明
- 影响程度
- 改进难度

## Opportunities - 机会
请列出 5-7 项外部机会：
- 机会的具体描述
- 时间窗口
- 利用难度

## Threats - 威胁
请列出 5-7 项外部威胁：
- 威胁的具体描述
- 发生概率
- 影响程度

## 战略建议
基于 SWOT 分析，提出：
1. SO 战略（利用优势抓住机会）
2. WO 战略（克服劣势抓住机会）
3. ST 战略（利用优势应对威胁）
4. WT 战略（克服劣势规避威胁）
```

### 框架 3：PESTLE 分析

#### 适用场景
- 宏观环境分析
- 战略规划
- 市场进入评估

#### 分析维度

```
Political（政治）
- 政策法规
- 政府态度
- 政治稳定性

Economic（经济）
- 经济增长
- 通胀水平
- 利率汇率

Social（社会）
- 人口结构
- 生活方式
- 文化价值观

Technological（技术）
- 技术趋势
- 创新速度
- 技术壁垒

Legal（法律）
- 法律法规
- 合规要求
- 知识产权

Environmental（环境）
- 环境保护
- 可持续发展
- 碳排放
```

#### NotebookLM 提示词模板

```
请用 PESTLE 框架分析[行业/市场]的宏观环境：

## Political - 政治因素
- 相关政策有哪些？
- 对行业有什么影响？
- 未来政策趋势？

## Economic - 经济因素
- 经济环境如何？
- 对需求有何影响？
- 成本结构变化？

## Social - 社会因素
- 用户行为有什么变化？
- 社会趋势如何？
- 对产品服务的影响？

## Technological - 技术因素
- 技术发展趋势？
- 技术壁垒在哪里？
- 创新机会？

## Legal - 法律因素
- 相关法规有哪些？
- 合规要求是什么？
- 法律风险？

## Environmental - 环境因素
- 环保要求？
- 可持续发展压力？
- 绿色转型机会？

## 综合评估
1. 哪些因素影响最大？
2. 哪些是机遇？
3. 哪些是威胁？
4. 应如何应对？
```

#### 适用场景

分析

- 重要程度
- 态度倾向

应对
- 如何沟通？

- 如何协同？
```

#### NotebookLM 提示词模板

```
请分析[项目/方案]的利益相关者：

## 利益相关者识别

## 利益相关者分析
对每个利益相关者分析：

### [角色名称]

- 沟通对象

- 沟通频率

### 框架 7：风险分析

#### 适用场景
- 项目评估
- 方案设计
- 决策支持

#### 分析维度

```
风险识别
- 可能出什么问题？

风险评估
- 发生概率
- 影响程度
- 风险等级

风险应对
- 规避
- 减轻
- 转移
- 接受
```

#### NotebookLM 提示词模板

```
请进行风险分析：

## 风险识别
列出所有可能的风险：
- 技术风险
- 市场风险
- 财务风险
- 运营风险
- 法律风险
- 人力资源风险

## 风险评估
对每个风险进行评估：

### [风险名称]
- **风险描述**：
- **发生概率**：高/中/低
- **影响程度**：高/中/低
- **风险等级**：[1-10分]

## 风险矩阵
请将风险映射到概率-影响矩阵中：
- 高概率+高影响：优先处理
- 高概率+低影响：需要监控
- 低概率+高影响：制定预案
- 低概率+低影响：可以接受

## 应对策略
对高风险项目，说明：
- 预防措施
- 应急预案
- 责任人
- 时间节点
```

## 🎯 多维度组合策略

### 策略 1：渐进式深入

```
第1层：表层分析（单维度）
   ↓
第2层：结构分析（2-3维度）
   ↓
第3层：系统分析（多维度组合）
   ↓
第4层：洞察提炼（综合判断）
```

**示例**：

```
# 第1轮：单一维度
"请从技术角度分析该方案的可行性"

# 第2轮：增加维度
"除了技术，请再从成本和时间角度分析"

# 第3轮：系统分析
"请综合技术、成本、时间、风险四个维度，
给出整体可行性评估"

# 第4轮：洞察提炼
"基于以上分析，最关键的3个洞察是什么？"
```

### 策略 2：交叉验证

```
从不同角度分析同一问题，
通过交叉验证提高结论可靠性
```

**示例**：

```
# 角度1：从客户需求
"从客户需求角度，这个方案的价值是什么？"

# 角度2：从技术实现
"从技术实现角度，这个方案的难度如何？"

# 角度3：从投资回报
"从投资回报角度，这个方案是否值得做？"

# 交叉验证
"以上三个角度的分析是否一致？
如果有矛盾，如何解释？"
```

### 策略 3：场景化分析

```
针对不同场景分别分析，
找出各场景的特定要求
```

**示例**：

```
# 场景1：理想场景
"在一切顺利的理想情况下，
该方案能达到什么效果？"

# 场景2：常规场景
"在正常情况下，
该方案的效果如何？"

# 场景3：最坏场景
"如果遇到最大阻力，
该方案还能成功吗？"

# 综合判断
"基于三种场景分析，
该方案的成功概率是多少？"
```

## 📋 实战分析流程

### 完整流程示例：企业数字化转型分析

#### 阶段 1：问题诊断（5W2H）

```
请用 5W2H 分析客户数字化转型面临的问题：
- What：问题本质
- Why：根本原因
- Who：谁受影响
- When：何时出现
- Where：哪些环节
- How：如何解决
- How much：投入多少
```

#### 阶段 2：环境分析（PESTLE）

```
请用 PESTLE 分析客户所处环境：
- 政策环境
- 经济环境
- 社会环境
- 技术环境
- 法律环境
- 环境要求
```

#### 阶段 3：现状评估（SWOT）

```
请用 SWOT 评估客户现状：
- 内部优势
- 内部劣势
- 外部机会
- 外部威胁
```

#### 阶段 4：方案设计（多维度）

```
请从以下维度设计解决方案：
- 技术维度：技术架构、系统选型
- 组织维度：人员配置、能力提升
- 流程维度：流程优化、变革管理
- 时间维度：实施阶段、里程碑
- 成本维度：预算分配、ROI评估
```

#### 阶段 5：风险评估

```
请进行风险分析：
- 识别主要风险
- 评估风险等级
- 制定应对措施
```

#### 阶段 6：利益相关者分析

```
请分析利益相关者：
- 识别关键人员
- 评估影响和态度
- 制定沟通策略
```

#### 阶段 7：综合建议

```
综合以上分析，提供：
1. 核心建议（3条）
2. 实施路径（分阶段）
3. 关键成功因素（5个）
4. 主要风险及应对
```

## 💡 高级技巧

### 技巧 1：建立分析地图

```
在开始前，先建立完整的分析地图

示例：
                    最终结论
                      ↓
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
    市场维度      技术维度      财务维度
        ↓             ↓             ↓
   ┌────┴────┐   ┌────┴────┐   ┌────┴────┐
   ↓         ↓   ↓         ↓   ↓         ↓
趋势  竞争  架构 可行  成本  收益
```

### 技巧 2：使用分析清单

```
## 分析清单
### 基础维度
- [ ] 问题层面（是什么、为什么）
- [ ] 现状层面（怎么样、为什么）
- [ ] 方案层面（怎么做、谁来做）

### 扩展维度
- [ ] 市场环境（PESTLE）
- [ ] 竞争态势（五力模型）
- [ ] 内部能力（SWOT）

### 深化维度
- [ ] 利益相关者
- [ ] 风险评估
- [ ] 时间维度
```

### 技巧 3：迭代深化

```
# 第1轮：框架搭建
"请建立[主题]的分析框架，
包括需要分析的关键维度"

# 第2轮：逐层深入
"请深入分析[维度1]的具体内容"

# 第3轮：关联分析
"请分析[维度1]和[维度2]之间的关系"

# 第4轮：综合洞察
"基于以上分析，提炼核心洞察"
```
