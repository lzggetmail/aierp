## 第一部分：基础概念

### 1.1 什么是飞书多维表格？

飞书多维表格 = **电子表格的灵活性 + 数据库的强大能力**

```
传统 Excel vs 飞书多维表格：

Excel：
├── 自由度高，但数据容易乱
├── 没有强制约束，可以随便填
├── 难以多人协作（容易冲突）
└── 数据关系难以维护

飞书多维表格：
├── 有字段类型约束（防止数据太乱）
├── 支持数据关联（类似数据库外键）
├── 天然支持多人协作（实时同步）
├── 多视图展示（表格、看板、甘特图等）
└── API 可编程（可以自动化）
```

---

### 1.2 核心概念

| 概念 | 说明 | 类比 |
|-----|------|------|
| **表格（Table）** | 一个完整的数据表 | 数据库的表 |
| **字段（Field）** | 表中的一列，定义数据类型 | 数据库的字段 |
| **记录（Record）** | 表中的一行数据 | 数据库的记录 |
| **视图（View）** | 同一数据的不同展示方式 | SQL 的视图 |
| **字段类型** | 字段的数据类型（文本、数字等） | 数据类型 |
| **关联字段** | 关联其他表的记录 | 数据库的外键 |

## 第二部分：字段类型详解

### 2.1 基础字段类型

```
1. 文本
   - 用途：短文本，如产品名称、客户名称
   - 示例："iPhone 15 Pro"

2. 多行文本
   - 用途：长文本，如产品描述、备注
   - 示例："这是一款高端智能手机..."

3. 数字
   - 用途：数值计算，如数量、金额
   - 示例：100、99.99

4. 货币
   - 用途：金额，自动添加货币符号
   - 示例：¥1,999.00

5. 百分比
   - 用途：百分比，自动添加百分号
   - 示例：25.5%

6. 日期
   - 用途：日期，如订单日期、交货日期
   - 示例：2026-03-18

7. 创建时间
   - 用途：记录创建时间（自动）
   - 示例：2026-03-18 14:30:00

8. 最后修改时间
   - 用途：记录最后修改时间（自动）
   - 示例：2026-03-18 15:30:00
```

---

### 2.2 选择类字段类型

```
9. 单选
   - 用途：枚举值，只能选一个
   - 示例：订单状态（待确认/已确认/生产中/已交付）

10. 多选
    - 用途：可以选择多个选项
    - 示例：产品标签（热销/新品/促销）

11. 级联选择
    - 用途：多级联动选择
    - 示例：地区（省 → 市 → 区）
```

---

### 2.3 人员与关系字段类型

```
12. 人员
    - 用途：选择飞书成员
    - 示例：销售员、负责人

13. 手机号
    - 用途：存储手机号码
    - 示例：13812345678

14. 邮箱
    - 用途：存储邮箱地址
    - 示例：user@example.com

15. 附件
    - 用途：上传文件
    - 示例：合同PDF、产品图片

16. 地理位置
    - 用途：存储地址信息
    - 示例：北京市朝阳区
```

---

### 2.4 高级字段类型（重点）

```
17. 关联字段（重要！）
    - 用途：关联其他表的记录
    - 示例：订单表关联客户表
    - 类比：数据库的外键

18. 查找字段
    - 用途：从关联记录中获取数据
    - 示例：订单关联客户后，自动显示客户地址

19. 公式字段
    - 用途：自动计算
    - 示例：金额 = 数量 × 单价

20. 汇总字段
    - 用途：汇总关联记录的数据
    - 示例：客户的订单总额（汇总该客户的所有订单）

21. 仪表盘字段
    - 用途：数据可视化
    - 示例：进度条、图表
```

## 第三部分：视图类型

飞书多维表格支持**多种视图**，同一份数据可以用不同方式查看：

### 3.1 表格视图
```
用途：传统表格形式
适用：数据录入、查看所有数据
示例：产品列表、订单列表
```

### 3.2 看板视图
```
用途：按状态分列展示
适用：任务管理、流程跟踪
示例：订单跟进（待确认/已确认/生产中/已交付）
```

### 3.3 画册视图
```
用途：卡片式展示
适用：产品目录、客户档案
示例：产品图片展示
```

### 3.4 日历视图
```
用途：按时间展示
适用：排期管理、任务计划
示例：生产计划、交付计划
```

### 3.5 甘特图视图
```
用途：项目进度管理
适用：项目型任务
示例：生产计划、项目进度
```

### 3.6 仪表盘视图
```
用途：数据统计和可视化
适用：数据分析、报表
示例：销售仪表盘、库存仪表盘
```

## 第四部分：数据关联

### 4.1 关联字段的作用

```
传统 ERP 的数据关系：
客户表 ←─────────────────→ 订单表
  │                          │
  │                          │
  └── 需要手动维护关系 ────────┘

飞书多维表格的数据关系：
客户表 ←── 关联字段 ────→ 订单表
  │                          │
  │                        自动关联
  └──────────────────────────┘
```

---

### 4.2 关联字段示例

假设你有两个表：**客户表** 和 **订单表**

**客户表结构**：
```
| 客户ID | 客户名称 | 联系人 | 电话 |
|--------|---------|--------|------|
| C001   | 张三公司 | 张三   | 138... |
| C002   | 李四公司 | 李四   | 139... |
```

**订单表结构**：
```
| 订单ID | 客户（关联字段）| 产品名称 | 金额 |
|--------|----------------|----------|------|
| O001   | 张三公司       | 产品A    | 1000 |
| O002   | 李四公司       | 产品B    | 2000 |
```

**操作**：
1. 在订单表中添加一个"客户"字段，类型选择"关联字段"
2. 关联到"客户表"
3. 添加订单时，可以直接选择客户

**好处**：
- ✅ 不需要手动输入客户名称
- ✅ 数据一致性好
- ✅ 可以使用查找字段自动获取客户信息

---

### 4.3 查找字段

关联字段后，可以使用查找字段自动获取关联记录的数据：

**订单表增强**：
```
| 订单ID | 客户 | 客户电话（查找字段） | 客户地址（查找字段） |
|--------|------|---------------------|---------------------|
| O001   | 张三公司 | 138...              | 北京市...            |
```

**好处**：
- ✅ 自动显示关联信息
- ✅ 数据不会出错
- ✅ 关联数据更新时自动同步

## 第五部分：公式与汇总

### 5.1 公式字段

公式字段可以**自动计算**数据：

```
示例 1：计算金额
字段：金额
公式：数量 × 单价

示例 2：计算利润率
字段：利润率
公式：(售价 - 成本) / 售价 × 100%

示例 3：判断库存状态
字段：库存状态
公式：IF(库存数量 < 100, "库存不足", "正常")

示例 4：文本拼接
字段：完整地址
公式：省 + 市 + 区 + 详细地址
```

---

### 5.2 汇总字段

汇总字段可以**汇总关联记录**的数据：

```
示例 1：客户的订单总额
客户表添加字段"订单总额"
汇总规则：汇总该客户所有订单的金额

示例 2：客户的订单数量
客户表添加字段"订单数量"
汇总规则：统计该客户的订单记录数

示例 3：产品的库存总量
产品表添加字段"总库存"
汇总规则：汇总该产品在所有仓库的库存数量
```

## 第六部分：权限控制

### 6.1 表格权限
```
可以设置：
- 谁可以查看表格
- 谁可以编辑表格
- 谁可以管理表格
```

### 6.2 视图权限
```
可以创建不同视图给不同角色：
- 老板视图：看所有数据
- 销售视图：只看自己的数据
- 财务视图：看财务相关数据
```

### 6.3 字段权限
```
可以设置某些字段的可见性：
- 普通员工看不到"成本价"
- 销售看不到"利润"
```

### 6.4 行级权限
```
可以设置记录级别的权限：
- 销售只能看到自己创建的订单
- 主管可以看到所有订单
```

## 第七部分：API 开发

### 7.1 飞书多维表格 API

飞书提供了完整的 API 来操作多维表格：

```
主要操作：
├── 创建记录
├── 查询记录
├── 更新记录
├── 删除记录
└── 批量操作
```

---

### 7.2 API 示例（Node.js）

```javascript
const lark = require('@larksuiteoapi/node-sdk');

// 创建客户端
const client = lark.Client.create({
  appId: 'your_app_id',
  appSecret: 'your_app_secret'
});

// 创建记录
async function createRecord() {
  const result = await client.bitable.appTableRecord.create({
    path: {
      app_token: 'your_app_token',
      table_id: 'your_table_id'
    },
    data: {
      fields: {
        '客户名称': '张三公司',
        '联系人': '张三',
        '电话': '13812345678',
        '订单日期': '2026-03-18'
      }
    }
  });

  console.log(result);
}

// 查询记录
async function queryRecords() {
  const result = await client.bitable.appTableRecord.list({
    path: {
      app_token: 'your_app_token',
      table_id: 'your_table_id'
    },
    params: {
      filter: `温控.[订单日期] >= "2026-03-01"`
    }
  });

  console.log(result);
}
```
