---

## 一、项目概述

### 1.1 项目目标

构建一个面向中小微制造业企业的 AI 驱动 ERP 系统，通过 AI 顾问的方式帮助企业发现经营问题、优化决策。

**核心价值**：让每个中小企业都拥有"全职 CFO + 运营顾问"

### 1.2 技术架构

```
双端架构：Web 端 + 飞书端
    ↓
后端数据库：SQL Server
前端数据库：飞书多维表格
AI 层：QClaw/QwClaw
```

### 1.3 开发原则

- **渐进式**：不推倒重来，逐步升级
- **快速验证**：先上 AI 特性，后优化底层
- **双端协同**：Web 管规范，飞书管便捷

## 三、开发环境搭建

### 3.1 前置要求

| 工具 | 版本要求 | 用途 |

| Node.js | 18+ | 前端和后端运行时 |

### 3.2 初始化项目

```bash
# 1. 创建项目目录
mkdir -p D:\AiERP\{backend,frontend,ai,feishu,docs,scripts}
cd D:\AiERP

# 2. 初始化 Git
git init
echo "node_modules/" > .gitignore
echo ".env" >> .gitignore
echo "*.log" >> .gitignore

# 3. 初始化后端项目
cd backend
npm init -y
npm install express mssql dotenv cors
npm install -D nodemon

# 4. 初始化前端项目
cd ../frontend
npm create vue@latest . --yes
npm install element-plus axios
npm install -D @types/node

# 5. 返回项目根目录
cd ..
```

### 3.4 配置飞书

#### 步骤 1：创建飞书企业

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 创建企业/组织
3. 进入"管理后台"

#### 步骤 2：创建飞书应用

1. 进入"应用管理"
2. 创建企业自建应用
3. 获取 App ID 和 App Secret

#### 步骤 3：配置权限

```
需要申请的权限：
✅ bitable:app - 获取多维表格信息
✅ bitable:app:readonly - 读取多维表格
✅ bitable:app:write - 写入多维表格
✅ im:message - 发送消息
✅ im:message:group_at_msg - 群组@消息
```

#### 步骤 4：创建多维表格

1. 在飞书中创建多维表格
2. 设计表结构（参考技术架构文档）
3. 获取 App Token 和 Table ID

## 五、核心功能实现指南

### 5.1 数据同步服务

```javascript
// backend/sync/services/sync-service.js
const sql = require('mssql');
const lark = require('@larksuiteoapi/node-sdk');

class SyncService {
  constructor() {
    this.sqlConfig = {
      server: process.env.SQL_SERVER,
      database: process.env.SQL_DATABASE,
      user: process.env.SQL_USER,
      password: process.env.SQL_PASSWORD,
      options: { encrypt: true }
    };

    this.feishuClient = lark.Client.create({
      appId: process.env.FEISHU_APP_ID,
      appSecret: process.env.FEISHU_APP_SECRET
    });
  }

  // 同步产品数据到飞书
  async syncProducts() {
    try {
      await sql.connect(this.sqlConfig);
      const result = await sql.query`
        SELECT * FROM products
        WHERE updated_time >= DATEADD(hour, -1, GETDATE())
      `;

      const records = result.recordset.map(row => ({
        fields: {
          '产品ID': row.product_id,
          '产品名称': row.product_name,
          '产品编码': row.product_code,
          '规格': row.specification,
          '单位': row.unit,
          '价格': row.price
        }
      }));

      await this.feishuClient.bitable.appTableRecord.batchCreate({
        path: {
          app_token: process.env.FEISHU_BITABLE_APP_TOKEN,
          table_id: 'products'
        },
        data: { records }
      });

      console.log(`同步了 ${records.length} 条产品数据`);
    } catch (err) {
      console.error('同步失败:', err);
      throw err;
    } finally {
      await sql.close();
    }
  }
}

module.exports = new SyncService();
```

### 5.2 AI Chat 机器人

```javascript
// feishu/bot/handlers/message-handler.js
const lark = require('@larksuiteoapi/node-sdk');

const feishuClient = lark.Client.create({
  appId: process.env.FEISHU_APP_ID,
  appSecret: process.env.FEISHU_APP_SECRET
});

async function handleMessage(event) {
  const message = event.message;
  const content = JSON.parse(message.content);

  // 解析用户消息
  const userText = content.text;

  // 调用 AI 处理
  const aiResponse = await callAIAgent(userText);

  // 发送回复
  await feishuClient.im.message.create({
    path: {
      receive_id_type: 'chat_id'
    },
    data: {
      receive_id: message.chat_id,
      msg_type: 'text',
      content: JSON.stringify({ text: aiResponse })
    }
  });
}

async function callAIAgent(text) {
  // 调用 QClaw/QwClaw 的 API
  // 这里需要根据具体的 AI 服务实现
  return `收到你的消息：${text}`;
}

module.exports = { handleMessage };
```

### 7.1 Docker 部署

```yaml
# docker-compose.yml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
    depends_on:
      - sqlserver

  frontend:
    build: ./frontend
    ports:
      - "80:80"

  sqlserver:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=your_password
    ports:
      - "1433:1433"
    volumes:
      - sqlserver_data:/var/opt/mssql

volumes:
  sqlserver_data:
```
