# AiERP - AI 驱动的轻量化企业诊断系统

> 让每个中小企业都拥有"全职 CFO + 运营顾问"

---

## 项目简介

AiERP 是一个面向中小微制造业企业的 AI 驱动 ERP 系统，通过 AI 顾问的方式帮助企业发现经营问题、优化决策。

### 核心价值

- **不是 AI 助手，而是 AI 顾问**：帮老板发现问题，而不只是帮员工干活
- **降低风险、优化决策**：替代昂贵的咨询顾问，提供实时经营洞察
- **双端协同**：Web 端管理规范业务，飞书端提供便捷 AI 交互

### 技术架构

```
双端架构：Web 端（Vue 3） + 飞书端（多维表格 + 机器人）
    ↓
后端数据库：SQL Server（核心业务数据）
前端数据库：飞书多维表格（汇总数据、任务数据）
AI 层：QClaw/QwClaw（AI Agent + Skills）
```

## 快速开始

### 环境要求

- Node.js 18+
- SQL Server 2019+
- Docker（可选）
- 飞书企业账号

### 本地开发

```bash
# 1. 克隆项目
git clone https://github.com/your-org/aierp.git
cd aierp

# 2. 安装依赖
cd backend && npm install
cd ../frontend && npm install

# 3. 配置环境变量
cp backend/.env.example backend/.env
# 编辑 .env 文件，填入你的配置

# 4. 启动开发服务器
npm run dev
```

详细说明请参考 [项目初始化与开发指南](./docs/项目初始化与开发指南_2026-03-18.md)

## 核心功能

### 1. AI 财务顾问

- 分析财务数据，发现潜在问题
- 预测现金流风险
- 识别亏损产品和问题客户
- 提供优化建议

### 2. AI 生产顾问

- 识别生产瓶颈
- 优化库存管理
- 提升产能利用率
- 降低质量问题

### 3. AI 人力顾问

- 评估岗位饱和度
- 优化人员配置
- 识别低效环节
- 预测人员需求

## 技术栈

### 前端

- Vue 3 + Vite
- Element Plus
- Pinia（状态管理）
- Vue Router

### 后端

- Node.js + Express
- SQL Server
- 飞书 API SDK
- QClaw/QwClaw

### 部署

- Docker
- 云服务器（阿里云/腾讯云）
